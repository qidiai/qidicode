## Part A — craft_verify.py（wordcraft CLI 自查脚本）

模块头 docstring：用途（精修闭环的 craft 自查：渲染关键页 PNG + 结构/文本回读，替代部分 WPS COM 截图与 python-docx 抽取）+ 风险引用（R19：wordcraft text 可能含修订删除文本，返回 revision_risk 标注；R22：wordcraft 排版与 WPS 有系统性度量偏差，渲染图仅供结构/内容自查，**不作为打印级排版比对依据**）。

CLI 解析（版本无关，抗升级）：
```python
def _resolve_cli() -> str:
    # env WORDCRAFT_CLI 优先；否则 glob G:\程序开发\artcraft\bin\wordcraft-*-windows-x64-portable\wordcraft-cli.exe 取版本号最大者
    # 找不到 → 所有子命令返回 {"ok": False, "error": "wordcraft-cli 不存在"}（JSON 到 stdout，退出码 2）
```

子命令（全部 JSON 输出到 stdout；exit 0=成功 1=操作失败 2=CLI 缺失）：

1. `render <docx> --pages <spec> --out <dir> --scale 2`
   - `--pages` 支持：`1,3,5` 显式页 / `mid`（⌈pages/2⌉，先 info 取 pages）/ `last` / `all`（上限 20 页防爆）
   - 每页调 `wordcraft-cli render <docx> <dir>/p<N>.png --page <N> --scale <S>`（页码 1-based）
   - 输出 `{"ok": true, "pages": [N...], "pngs": [paths...], "ms": N}`；某页失败 → 该页记 error 继续，最终 ok=false 若有失败

2. `text <docx>`
   - 调 `wordcraft-cli text`；**R19 标注**：zipfile 只读 word/document.xml 正则计数 deltext/sym/txbx（模式同 craft_bridge._revision_risk，独立实现禁止 import）
   - 输出 `{"ok": true, "text": "...", "chars": N, "revision_risk": {...}}`

3. `inspect <docx>`
   - 调 `wordcraft-cli info` 取 JSON（pages/paragraphs/words/trackChanges…）
   - 输出 `{"ok": true, "info": {...}, "text_chars": N}`（text_chars 由 text 子命令同路径计算，不重复抽则省略）

4. `--selftest`（自包含，不依赖真实语料）
   - python-docx 造 fixture docx（含中文段落"整改测试内容"+注入 w:delText 的修订删除段）
   - 断言：render p1 PNG 生成且 >1KB；text 输出含"整改测试内容"；revision_risk.deltext_count>0；inspect ok
   - 全过打印 `SELFTEST OK` 退出 0；任一失败退出 1

约束：仅 stdlib（subprocess/zipfile/re/glob/json/pymupdf 不引入——render/text 全靠 CLI）+ python-docx（仅 selftest fixture 用）；超时单次 180s、render 每页 180s；大 text 只写文件不刷屏（--out 模式可选落盘）。
