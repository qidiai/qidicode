## craft_bridge.py 功能规格

### 0. 模块头与依赖
```python
# -*- coding: utf-8 -*-
"""craft_bridge — ArtCraft craft CLI 统一子进程包装（W5）。

风险登记册引用：
  R5  退出码语义表（wordcraft 0/1/101；gridcraft check 0/1/2）
  R19 wordcraft text 输出 w:delText/w:sym——text() 必须返回 revision_risk 标注
  R21 wordcraft convert→PDF 文本层 88.5% 丢失——convert() 文档串必须警示"交付级 PDF 禁用"
  R24 pdfcraft 中文文本水印被拒——watermark_file() 仅走图片水印
"""
```
依赖仅 stdlib（subprocess/os/time/re/json/typing）+ `from utils.logger import get_logger`。模块级 `log = get_logger('craft_bridge')`。

### 1. 退出码语义表（模块常量，写死）
```python
RC_SUCCESS = 0
RC_BIZ_FAIL = 1          # wordcraft 业务失败 / gridcraft check 有 mismatch
RC_USAGE_FAIL = 2        # gridcraft check 用法错误（专用）
RC_PANIC = 101           # Rust panic
RC_TIMEOUT = "TIMEOUT"   # 本包装语义
RC_NOEXE = "NOEXE"       # 本包装语义
```

### 2. 底层执行
```python
def _kill_tree(pid: int) -> None
    # taskkill /PID <pid> /T /F（subprocess，捕获 OSError）
def _run(cli_path: str, args: list, timeout: float = 180) -> CraftResult
```
- `CraftResult` dataclass：`rc: int|str, stdout: str, stderr: str, cmd: list, ms: float`，`ok` 属性 = `rc == 0`
- **一律 `subprocess.run([cli]+args, capture_output=True, timeout=timeout)`**——读满管道（BrokenPipe 假成功防护：调用方绝不提前关管道/截断读取）
- `TimeoutExpired` → 先 `taskkill /T /F` 兜底杀进程树（subprocess.run 只杀直接子进程）→ 返回 `rc=RC_TIMEOUT`，附已捕获输出
- `FileNotFoundError/NotADirectoryError/PermissionError/OSError` → `rc=RC_NOEXE`
- UTF-8 decode errors="replace"（坏字节计入 U+FFFD 由调用方观测）
- 每次 invocation 记 log.info("cmd=%s rc=%s ms=%.0f", ...)，rc!=0 加 log.warning（含 stderr_head 200 字）

### 5. 类型化封装（三个类，方法先做 `_run` 再做薄封装）
```python
class WordCraft:
    def info(path, timeout=180) -> dict            # json.loads stdout；失败返回 {"parse_error": stdout[:300]}
    def text(path, timeout=180) -> dict            # {"text","revision_risk"} ← R19 标注（risk 时附 "warning" 键）
    def render(path, out_png, page, scale=2.0, timeout=180) -> CraftResult + png 存在性/大小
    def convert(src, dst, timeout=300) -> CraftResult  # docstring 必须：⚠️ R21 交付级 PDF 禁用（文本层 88.5%），仅内部预览
class GridCraft:
    def check(target, timeout=600) -> dict         # 语义按 0.6.1 实测钉死：rc==0→"all_pass"（no_oracle/volatile 计数为 informational）
                                                   #   rc==1 且输出（stdout+stderr）含 "can't open" → "open_error"；rc==1 其他 → "mismatch"；rc==2 → "usage_error"
                                                   #   ⚠️勘误（glm-5.3 审计 S4，实测）：can't open 行实际在 **stdout**（stderr 为空，check.rs:1022 outln!）——实现对 stdout+stderr 一并匹配（超集不误伤）
                                                   #   detail 携带 stdout 的 formulas 计数行（如 "1 no oracle, 0 volatile"）
    def convert(src, dst, timeout=300) -> CraftResult
class PdfCraft:
    def combine(paths: list, out, timeout=300) -> CraftResult
    def split(src, every, out_dir, timeout=300) -> CraftResult
    def extract(src, pages: str, out, timeout=300) -> CraftResult
    def watermark_file(src, png, out, timeout=300) -> CraftResult  # ⚠️ R24：中文水印必须走本图片模式；文本模式仅西文
    def text(src, timeout=180) -> CraftResult
```
每类构造时 `_resolve_cli(self.APP)` 一次存 `self.exe`。

### 6. 便捷门面（供 services 调用）

```python
def pdfcraft_combine(paths, out) / pdfcraft_extract(src, pages, out) / pdfcraft_watermark_file(src, png, out)
```
