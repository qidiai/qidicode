## 功能规格

### 1. sampling.py — 抽样（配额数字已实测写死）
```
build_manifest(corpus_root, seed=20261012) -> list[dict]
```
- 语料根：`G:\投标docx库`（可参数覆盖）
- 池与配额（排除规则优先）：
  - **A 标书本体 25 份**：`投标文件\**\*.docx`，**排除**路径含 `业绩` 的、排除 >50MB
  - **B 业绩合同 10 份**：`投标文件\业绩\**\*.docx`，排除 >50MB
  - **C 审查/共享 10 份**：`Desktop\**` ∪ `审核标书\**`，排除 >50MB
  - **D 大件冒烟 5 份**：全库 >50MB 按大小降序取前 5
- 每池用 `random.Random(seed).sample(pool_sorted, quota)`；pool 先按路径排序保证确定性
- manifest 条目：`{"path","size_mb","tier"}`；写 `_craft_eval/out/manifest.json`

### 2. truth.py — w:t XML 真值抽取
```
extract_truth(docx_path) -> {"raw": str, "norm_chars": int, "del_chars": int, "error": str|None}
```
- zipfile 打开 docx，读 `word/document.xml`
- ElementTree 解析，命名空间 `w=http://schemas.openxmlformats.org/wordprocessingml/2006/main`
- 收集**全部 `{w}t` 元素文本**，**剔除**：任何祖先是 `{w}del` 的 `{w}t`（删除修订文本），剔除量计入 `del_chars`
- 拼接为 `raw`；`norm_chars` = raw 去除全部 `re.sub(r'\s', '', raw)`（含全角空格 U+3000，\s 在 Python3 str 模式已覆盖）后的字符数
- 打不开/解析失败 → `error` 字段，不抛异常

### 3. cli.py — wordcraft-cli 子进程包装
```
class WordcraftCLI:
    def __init__(self, exe_path=None)  # 默认 G:\程序开发\artcraft\bin\wordcraft\wordcraft-cli.exe，env WORDCRAFT_CLI 覆盖
    def info(path, timeout=180) -> {"rc","json"|None,"parse_error","stdout_head","stderr_head","ms"}
    def text(path, timeout=180) -> {"rc","out","err","ms"}
    def render(path, out_png, page, scale=2.0, timeout=180) -> {"rc","err","ms","png_bytes"}
```
- 一律 `subprocess.run(args, capture_output=True, timeout=...)`；**读满输出，禁止提前关管道**（wordcraft 把 stdout 关闭当成功，假成功陷阱）
- `info`：stdout 尝试 `json.loads`；失败时 `json=None, parse_error=stdout[:300]`
- `text`：stdout 全文（UTF-8 errors=ignore）
- `render`：`render <file> <out.png> --page <N> --scale <S>`；记录生成文件大小
- 退出码语义（写死为常量表）：0=成功，1=业务失败，101=Rust panic，其他原样记录
- TimeoutExpired 捕获后返回 `{"rc":"TIMEOUT"}`，不抛

### 4. metrics.py — 判据
```
u_fffd_count(text) -> int                    # U+FFFD 替换字符计数，放行要求 ==0
completeness(craft_text, truth_norm_chars) -> {"ratio","craft_norm"}   # norm(craft)/truth，>1.0 记录原值
cjk_ratio(text) -> float                     # CJK 字符占比，用于真值漂移对照
norm(text) -> str                            # 与 truth.py 同一规整规则（放这里，truth.py 引用）
```

### 5. run_w2.py — 主入口（argparse）
- `--selftest`：转调 selftest.main()，全过打印 `SELFTEST OK` 退出 0
- `--probe`：CLI exe 不存在 → 打印 `{"error":"cli_missing","path":...}` 退出码 **2**；存在 → 取 A 池最小文件跑 info+text+render(第1页) 打印 JSON 退出 0
- `--preflight`：A/B/C 各取 小(<1MB)/中(1-10MB)/大(10-50MB) 共 3 份全流程（info+text+render×3页），输出逐项耗时 ms + 按 45 份线性外推 ETA
- `--run`：manifest 全量执行；每份：info 取 pages → text → render 第 1 / ⌈pages/2⌉ / pages 三页（scale=2，PNG 存 `_craft_eval/out/pages/<序号>/`）；**D 组只跑 info**（600s 超时）不进统计
- 每文件记录 `_craft_eval/out/records/<序号>.json`：`{path,tier,size_mb,rc_info,rc_text,rc_render,pages,ms_info,ms_text,ms_render,truth_norm,craft_norm,completeness,u_fffd,cjk_truth,cjk_craft,verdict}`
  - verdict：`ok` / `fail_text`(rc!=0或空) / `fail_render` / `panic`(rc==101) / `parse_error` / `timeout` / `truth_error`
- 聚合 `_craft_eval/out/report.json` + `report.md`：A/B/C 分层统计（n、完整率均值/中位/最小、U+FFFD 总数、失败清单、耗时统计）；**D 组单列**；每个数字带来源字段（命令、rc、ms）
- 超时：常规 180s/调用，D 组 info 600s；并发：串行（首轮不求快）

### 6. selftest.py — 自测（**不依赖真 CLI、不读真语料**）
- 用 python-docx 1.2.0 造 4 个 fixture：纯段落 / 含表格 / 含全角空格与 CJK / 底层 XML 注入一段 `{w}del` 包裹的 `{w}t`（修订删除）
- 断言：
  - truth 抽取纯段落 fixture == python-docx 提取的段落全文
  - `w:del` 内文本被剔除且 del_chars>0
  - norm 计数正确（含全角空格清除）
  - metrics：U+FFFD 计数（造含 U+FFFD 的串）；completeness 同文本=1.0；缺字<1.0
  - sampling：同 seed 两次 build_manifest 结果完全一致；A 池 manifest 无 >50MB、无"业绩"路径；D 组是按大小前 5
  - sampling 池统计打印（A≈502/B≈839/C≈52/D=25 只读计数，不抽样执行）
- 全过打印 `SELFTEST OK`，任何断言失败退出码 1

## 约束

- Python 3.12 + **stdlib + python-docx(1.2.0) 仅此**，禁止新增第三方依赖
- 全部源文件 UTF-8；任何 print 中文先 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')`（本机 PS5.1 GBK 坑）
