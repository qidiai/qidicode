## Part B — craft_convert.py（标书软件 skill_assets/office-tools/scripts/）

**风格**：遵循脚本家族惯例——`"""...CLI tool. Usage: python craft_convert.py <command> [args]"""` + argparse 子命令 + print 输出（可 --json）。模块头 docstring：用途（craft CLI 统一格式转换包装）+ 风险引用（R19 修订文本 / R21 docx→pdf 文本层 88.5% 丢失默认禁用 / R24 中文水印不在本脚本范围）。

**CLI 解析**（与 craft_verify 同模式，独立实现禁止 import qidicode 代码）：
- env `CRAFT_CLI_<APP>`（如 CRAFT_CLI_WORDCRAFT）优先；否则 glob `G:\程序开发\artcraft\bin\<app>-*-windows-x64-portable\<app>-cli.exe` 取版本号最大者（语义化版本比较）；三 app 均缺失时子命令返回 JSON {"ok": false, "error": ...} 退出码 2

**子命令**（全部输出 JSON 一行 {ok, rc, out, ms, detail}，exit 0=成功 1=失败 2=CLI 缺失）：

| 子命令 | 实现 | 验证 |
|---|---|---|
| `docx2md/html/txt/odt/rtf/json <in> <out>` | `wordcraft-cli convert`（一个子命令带目标格式参数或六个薄封装，任选其一）| out 存在且非空；md/txt 抽内容断言含源文档首段文本 |
| `xlsx2csv/json/html <in> <out>` | `gridcraft-cli convert` | csv 非空、含源表首个单元格值 |
| `pdf2text <in> [--out 文件]` | `pdfcraft-cli text` | 输出页数标记与源 PDF 页数一致（pypdf/fitz 计数） |
| `docx2pdf <in> <out> --force` | **无 --force 一律拒绝**（退出码 1 + R21 警示文案：wordcraft convert→PDF 文本层重度丢失，交付级 PDF 走 WPS COM）；有 --force 才调 wordcraft-cli convert | 拒绝路径返回 R21 文案；force 路径产物存在 |
| `info <file>` | 按扩展名路由到对应 craft-cli info（docx→wordcraft/xlsx→gridcraft/pdf→pdfcraft）| JSON 含页数等关键字段 |

**边界声明**（docstring 明列）：合并/拆分/水印/表单 → `services/pdf_bindery.py` 与 `pdf_ops.py` 领地，本脚本不做；pdfplumber 表格结构强项的抽取仍以 `pdf_ops.py` 为准，本脚本 `pdf2text` 为 pdfcraft 引擎备选；docx→docx 不做（无意义）。

**--selftest**：python-docx 造含中文段落 fixture docx + openpyxl 造 xlsx → ①docx2md 产物含中文段落 ②xlsx2csv 含单元格值 ③docx2pdf 无 --force → ok=false 且 detail 含 "R21" ④pdf2text 对自造 2 页 PDF → 输出含 2 页标记 ⑤info 对 docx → ok=true。全过打印 `SELFTEST OK` 退出 0。
