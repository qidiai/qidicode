### F1（阻断级）：无 T0 对照臂——R1/R2 无法定位矛盾任何一方

88.98/88.82 是**绝对值**。本容器没有"模块关闭"的 T0 基线，于是 88.98 落在 T0 的 -1.95% 侧还是 +6% 侧**无从判断**：若本容器 T0 ≈ 90.8，R1 复现 C 线方向；若 T0 ≈ 83.9，R1 反而站台式机一侧。R1/R2 回答的是"初始化敏不敏感"，**没有回答"T3 好还是坏"**——而后者才是归因矛盾的本体。一个 10ep NPU run 即可关闭此缺口，是全案性价比最高的缺失实验。

### F2（阻断级）：主嫌疑未被触碰，且候选清单漏了第四项

归因候选 ①数据子集 ②栈实现 ③随机性 中，R1/R2 **恒定了栈与数据**，两臂之间只变初始化。它的净贡献 = 从扩展后的五候选清单（①数据 ②栈 ③随机性 ④评测口径 ⑤初始化口径）里划掉了第五项。审计补充第四候选 **④评测口径**：台式机侧的 val 切分方式、PPL 归约（逐 token vs 逐 chunk）、有效上下文长度若与 v10 不同，可直接制造百分比级系统差——跨侧比较前未做口径对齐清单，是 +6% vs -1.95% 可比性上的空洞。

### F3（阻断级·实现层）：R2 双零起点的梯度死锁推演——破锁机制未文档化

设模块贡献 y = α·h(x; W_read, W_write, W_pool)（最外层乘性门假设）。R2 起点 α=0 且 W 全零：

- 若 h(x; W=0) ≡ 0（严格无 bias、无非参数路径），则 ∂L/∂α = ⟨∇y, h⟩ = 0，且 ∂L/∂W ∝ α = 0——**四组参数梯度同时精确为零，构成严格驻点**。AdamW 无济于事：weight decay 向零推、ε 不产生零之外的位移。精确算术下 R2 应永锁，α 恒为 0。
- **实测 α(E8)=0.09 ≠ 0 → 死锁确实被打破 → 必然存在未文档化的破锁前提**。最可能：`nn.init.zeros_(weight)` 是惯用写法而 **bias 漏置零**（PyTorch 默认 bias 非零 uniform）——则 h(x;0)=b≠0，∂L/∂α≠0，α 先离开零，随后 W 梯度随 α≠0 解冻，Adam 的归一化再放大小梯度。此机制与"α 长到 0.09 且性能正常"的观察完全自洽。次可能：α 不在最外层乘性位置、或 h 内含常数路径。

**后果分派**：若破锁成立（如 bias 未置零），R2 实为"零 weight + 随机 bias"起步，"恒等起步"措辞不严格，但作为"近零初始化口径"与 R1 打平仍支持初始化不敏感——**排除结论对 R2 实际口径的扰动是鲁棒的**；但"严格恒等自证"的物理叙事必须待代码证据（init 代码段 + 前向图）才能恢复证据资格。这是本案最高优先级的未关闭项，**读代码近零成本，没有理由不关**。

### F4（严重级）：单 seed、σ 缺失——以及它指向的"虚惊假说"

两臂各一 run、训练 seed 未披露（若 R1/R2 seed 不同，0.18% 还混合了 seed 差异），run-to-run 方差从未测得。于是：0.18% 与 -1.95% 谁在噪声内、+6% 是否超出随机性解释范围，**全部无法判定**。注意 NPU 算子非确定性使"同 seed 复跑"也可能有差——σ 有两个分量（seed 方差 + 硬件非确定性），应分别测。

由此提出审计方认为**当前证据权重最高**的工作假说：若模块在 6.6M/wiki 预训练上的真实 T3 效应 ≈ 0，则 -1.95%（C 线单读数）、+6%（台式机单读数）、±0.18%（R1/R2）三组数**并不互相矛盾**——它们是同一零效应上的不同噪声采样，"矛盾"本身可能是读数问题而非机制问题。该假说与 120M SFT 的 -28.6% 不冲突（规模与任务均不同）。证伪成本：3-4 个 10ep run。

### F5（中）：α 的乘积简并——0.09 与 1.08 不可同台比较

模块有效增益 ∝ α·f(‖W‖)：R2 的 W 从零长出，α 与 ‖W‖ 互相补偿，R2 停在 (0.09, 大W)、R1 停在 (1.08, 小ΔW) 是同一平坦谷的两个解。从"α 只长到 0.09"推"模块效应弱"是**过度解读**；正确推论是：**α 终值差 12 倍而 PPL 相同 → (α, ‖W‖) 平面存在平坦谷 → 模块对本任务 PPL 的边际贡献不敏感**。"弱效应"结论成立，但定量证据应换成**模块输出对残差流的贡献范数**或消融前后 PPL 差——summary 均未记录。

### F6（中）：跨侧比较的口径未对齐

台式机"不同数据子集"意味着：子集 max_id 是否满覆盖未知（若 <8192 则有 dead embedding 行，有效参数与梯度分布不同）；候选①的正确机制化表述不是"子集难度"，而是**子集×模块交互**（数据分布决定模块读/写/池化行为是否有收益）；再叠加 val 切分与 PPL 归约可能不同——+6% vs -1.95% 在口径对齐前是苹果比橙子。

### F7（轻）：训练预算的双重身份

51.2M tokens / 6.6M 参数 ≈ 7.8 tokens/param，低于 Chinchilla 参考（~20×）约 2.6 倍——绝对意义上欠充分训练。但 A/B 对照只要求两臂**同预算**：双 E8 best、cosine 末端无刷新表明预算内已到平台，对照内部自洽。结论应限定为"同预算对比"，不可外推"充分训练"语境；E8 后无提升也与 20K 子集重复 10 遍的轻过饱和一致，两臂选择规则一致故公平性保持。

### F8（轻）：参数账与模块占比未披露

hidden 512 / 8L / 8H(GQA nkv=2) / vocab 8192 的常规构成粗算难以直接落到 6.6M（取决于 MLP 中间维与 embedding 是否 tying），存在多种无害解释，不作否决项；但 **GravityField 参数占比未披露**削弱了"弱效应"先验的量化基础，且 R1/R2"其余完全一致"的声称目前无 config diff/hash 佐证，只能采信。

### F9（轻）：120M SFT -28.6% 的证据边界

不同规模（120M vs 6.6M）、不同任务（SFT 遗忘 vs 预训练 PPL），**不能作为 6.6M 归因的证据**，只能作为"模块价值显现条件"的边界注记（模块收益或在 SFT 遗忘场景显著、在 wiki 预训练 PPL 上不显著——两者不矛盾）。其自身的测量设计不在本审计范围。

## 四、发射门裁决

**裁决：NO-GO（归因结论不予放行；"初始化口径排除"作为弱结论允许记档）。**

**理由三支柱**：
1. **缺 T0**（F1）——主问题"全层 T3 究竟好 or 坏"在本容器内无定位，R1/R2 的 88.9x 是无锚点数字；
2. **单 seed 无 σ**（F4）——所有等价判断与量级论证（0.18% ≪ 6%）无统计效力，且"虚惊假说"（真实效应≈0，矛盾是两次噪声采样）当前证据权重最高而未检验；
3. **R2 破锁机制未证**（F3/R-009）——R2 臂的口径描述与其测量对象之间的对应关系悬置，近零成本的代码核对未做即报 DONE，属流程瑕疵。

**允许记档的弱结论**（措辞须严格限定）："在本容器、v10 栈、wiki_r12_20k、单 seed 条件下，GravityField 在两个极端初始化口径（α=1+随机 Linear vs α=0+全零）下 best val PPL 差 ≤0.18%，初始化口径不是台式机 +6% 翻转的合理解释方向（量级论证，待 σ 佐证）；模块在 6.6M/wiki 预训练上呈弱效应/平坦谷特征。"

**复审放行条件（checklist）**：
- 必备集（放行"初始化排除"为正式结论）：① T0 臂落地；② ≥3 seed σ（含同 seed 复跑）；③ R2 init 代码证据 + 贡献范数曲线；
- 归因最终结论追加：④ 2×2 交叉至少两格 + 评测口径对齐清单闭环。

**收尾评语**：R1/R2 的执行质量本身合格——双 run 完整、数字自洽、同预算公平、双 E8 best 相互印证。发射门拦下的不是这两个 run，而是"以合格实验包装不完整归因"的叙事惯性：被排除的候选本就是清单里最弱的一个，主嫌疑三人仍在场。下一步应把火力转向 σ 与 T0——三个 run 的成本，即可让 -1.95%、+6%、±0.18% 三组数字从"互相矛盾"变为"互相解释"。
