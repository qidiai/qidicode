## 一、自由审查发现（严重度排序；标注 Step5 已抓 vs 本审计新增）

### S1 级（阻断开工/冻结）

**F-01【新增】Loop 机制缺实现级金标准**——三闸门验证全是"pp2 vs 单卡同套代码自洽"（共享 bug 双双通过）；C 线证据由 C 线 28M 代码栈产生，M5.1 是新栈（transformers 5.18 + 手写 pp2）重新实现 loop。若 pass-2 输入构造/RoPE 偏移/掩码/状态携带两栈漂移，Phase A 结果相对 C 线趋势不可解释。修复：确认两线 loop 代码同源性；不同源则在 28M 模型上回放 v3 loop 实现，复现 C 线已测签名点（28M 回放成本可忽略）；pass-2 精确规范随 G1 预注册。

**F-02【新增·双方共同盲区】线性注意力 recurrent state × batch/序列边界**——训练中线性层状态必须每序列零初始化；参考实现常为推理取向保留跨调用持久缓冲，沿用即跨样本信息泄漏（静默正确性 bug：loss 照常下降、结果全废）。G1 只预注册了 pass 边界，漏了 batch 边界与训练/评估双模式。修复：G1 文档增"batch/序列边界重置+双模式"条目；--verify 增连续两批置换检验（[A,B] 与 [B,A] 各样本输出逐样本一致）。

**F-03【新增·对应 Step5 G3 修订】--verify 三层结构性缺陷**——(a) no_grad 单卡基准无法对照梯度（只能抓死路径，抓不住错梯度）；(b) Step5"首3层+尾4层"梯度断言在尾4-LoRA 布置下**字面不可满足**（无上游可训练参数则反向链在 layer 60 输入自然终止，跨 stage 梯度交接根本不被行使）；(c) 激活 ckpt 语义仅文档归档非断言。修复：三层验证协议——tier-1 前向等价（生产 ckpt-on，b1×2048）**前置**；tier-2 小配置带梯度对照（b1×512 级，单卡 vs pp2 比较可训参数梯度）；tier-3 全配置 LoRA 梯度非零断言 + 合成 card0 临时可训练参数专门行使跨 stage 交接后删除。

### S2 级（对应工件冻结前必修）

**F-04**：执行序缺陷——G2 吞吐扫描跑在未验证的 pp2 实现上（线性注意力若静默走退化核，step time"异常地好"，配置选择失真）。tier-1 verify 前移到扫描之前。执行序修订：代码→层型导出→tier-1 verify→网格扫描→G1→G2→tier-2/3→冻结→开工。
**F-05**：2-5× 惩罚无基准（两个输入——混线比=层型图产物、单层惩罚=微基准——均未测，禁入预算依据）；50% 燃尽触发滞后；缓解路径科学代价不对等（**降 seq 破坏研究对象**——loop 是长语境现象；换基座=重启 M5.1；只有 AscendC 融合核语义中性）。修复：单层微基准实测分解 + G2 关账前置预测评估 + 缓解路径按科学代价分级预注册。
**F-06【共同盲区】**：微批数/流水线气泡/有效 batch 与 C 线可比性——b1 在 pp2 下两阶段近半闲；有效 batch 随 m 变化改变优化语义。修复：扫描预注册钉死（m、调度、ckpt、in-flight）；吞吐表附气泡注记；与 C 线可比性声明。
**F-07**：逐位一致判据的 NPU 跨 world size 确定性未验证——须预注册容差回退协议，不得临场放宽。
**F-08**：测量口径未钉死——57.95G 构成、GB/GiB、5120 须从模块参数形状确证（config 读取路径已知出过静默错读）、vocab 缺失下每卡 25.5G 为粗分。config 读取器加关键字段断言（64 层/5120/GQA/vocab 非空）。
**F-09**：R-C/R-D 无闸门归属——transformers 5.18×torch_npu 回归须落为扫描前置 smoke 清单（含 save/load 往返与生成路径，当前零覆盖）；R-D 显式入执行链。
**F-10**：50 步/5 采样点对缓涨碎片不充分——修复：HBM 斜率外推至主臂目标步数的投影峰值 + allocated/reserved 双口径 + 主臂运行期 watchdog；step time 取稳态中位数（排除首步建图）。
**F-11**：G1 三情形树**索引对象错误**——按骨干组成索引则"全线性/全全注意力"两支已被材料自证死亡（骨干=混合）；应按 **loop 段（60-63）的组成**索引，段内混合显式成支；段内每个线性层单独定义 pass-2 机制（线性层无 KV，"经 KV 重读"语义原理上不存在）。移位准则预注册"尾部机制保真 vs 可迁移性"优先序，禁临场裁。
**F-12**：量纲重标定时点混淆（C 线自身修正项）——拆三级：常量重推导=**Phase C 前**硬门（GF 不进 Phase A 主臂）；窗口设计规格=G1 冻结前；GF@5120 规格=已完成。原"Phase A 前"承诺标注错误，予以更正。
