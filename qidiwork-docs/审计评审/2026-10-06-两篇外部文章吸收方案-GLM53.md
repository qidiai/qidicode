## 一、专利叙事吸收（最高优先）

### 1.1 Cadence「做梦自回放」vs 白泽 replay 剂量曲线——逐点判定

我方事实底座〔矩阵§3①/⑤〕：replay 四点 7%→+41.3% / 26%→+13.0% / 40%→+11.1% / 53%→+9.3%（30k 冒烟）+ 全量 53%/26 倍剂量→+28.2%（白泽 1.0）+ 容量相变：26M 挤出（+28.2%）vs 120M 共存（pre 39.79→post 28.41，−28.6% 反向 PASS）。
Cadence 事实：语法归纳 不睡 81.5% / 加练两轮 90.5% / 做梦自回放 100%。

| 判定点 | 判定 | 依据 |
|---|---|---|
| 是否同一问题 | **否。不同设定** | 我方=离线 SFT 迁移时混入**真实旧语料**防遗忘；它=推理期终身学习，**自记录 episode 夜间重放**做巩固 |
| 是否同轴（方向）佐证 | **是，弱同轴** | 它在另一设定复演"回放>被动加练"（90.5→100 同预算对照），与我方"回放配比↑→漂移↓"方向一致；但无数值交换可能，两套数字不可互换 |
| 是否同量纲 | 否 | 我方 x 轴=优化剂量当量（步数×LR 积分，注册单位，〔矩阵§3①〕）；它只有"8000 轮"单点，无剂量-响应函数 |
| 可否引作遗忘门章节旁证 | **可以，限 1-2 句** | 必要（防"回放防遗忘仅此一家"质询）且不重叠（我方定量贡献=剂量曲线+容量阈值 4.6×〔矩阵§3⑤〕） |

**建议措辞（直接入下一版会签遗忘门章节）**：
"他山同类旁证（设定不同，仅方向一致）：2026-09 开源 Cadence 框架（MIT）在推理期终身学习设定下报告'夜间自回放（100%）优于外部加练（90.5%）'。本专利问题设定不同（离线 SFT 迁移 vs 推理期终身学习）、回放数据源不同（真实旧语料按优化剂量当量混合 vs 模型自记录重放），定量贡献为剂量-漂移曲线（7%→+41.3%…53%→+9.3%，全量 +28.2%）与容量阈值效应（26M SFT +28.2% vs 120M −28.6%），与该工作无重叠。"（差异化杀招另加一句：Cadence 结构容量被连接组刚性掩码锁死，**原理上不可能出现容量相变**——26M/120M 开关是我方独占证据。）

### 1.2 loop 收敛 ↔ 均衡沉降——定位语不改写为"均衡传播谱系"

- 计算形式有亲缘：我方 loop=T2/T3 逐块迭代收敛（收益 6.6M −1.95%〔矛盾未决，虚惊假说权重最高〔矩阵§3④〕〕、28M −2.81%、28M@223M −7.8~−10.0%、120M 轻训 +0.04%≈零〔矩阵§2/§3③〕）与均衡沉降"迭代至亚稳态后读答案"同属**迭代收敛计算**；R1/R2 两种初始化口径终值仅差 0.18%（88.98 vs 88.82，α=1.08/0.09）收敛至同一功能态〔矩阵§3④〕，有"终态主导"的回声。
- 学习法定义性区别：我方=标准反向传播穿透展开步；Cadence=Bengio 系均衡传播局部轻推、无 BP 管道。**谱系分界线在此，故不改写**。理由：loop 收益本身 regime-dependent 且 6.6M 点悬而未决（虚惊假说），此时挂靠 EP 热词会在审查质询中反受其害；（c）我方 loop 主张只绑定"跨尺度实测矩阵+三区判例"〔矩阵§2〕这一实证资产，与任何形式亲缘解绑更安全。
- 可执行动作：向专利代理人备 1 句质询预案——"两者共享迭代至收敛态的计算形式；白泽以反向传播训练，与均衡传播为不同学习法谱系；loop 主张仅以跨尺度实测矩阵为据。"

### 1.3 白泽 vs Cadence 差异点清单（防混淆）

| 维度 | 白泽（我方） | Cadence（外部） |
|---|---|---|
| 结构 | token 化 LoopedTransformer（GQA/attention），26M–120M，昇腾 NPU | 速率单元连续动力学+真实线虫连接组**刚性掩码**，无 token/注意力 |
| 学习法 | 反向传播（AdamW，lr 1e-5/batch 32） | 均衡传播局部轻推 |
| 回放数据 | 真实旧预训练 chunks，按配比混入 | 模型自 Playback Store（白采 episode，夜 8000 轮自生成重放） |
| 回放目标 | 防灾难性遗忘（门 ≤10%，节奏靠剂量旋钮） | 技能巩固+泛化（81.5→100） |
| 定量律 | 剂量当量响应曲线+容量 4.6× 相变〔矩阵§3⑤〕 | 单系统三对照，无剂量函数 |
| 生产目标 | 小模型 NPU 部署+可控 SFT 迁移 | 终身在线学习具身体 |

### 1.4 夸张剥离（①"掀翻大模型"）

采信作者自画三条红线：速率单元非脉冲神经元；**错误记忆会被做梦放大**（与我方 d18 编造天气/化学错误实锤同向〔裁决包 关键发现 3〕，是移植做梦的自带风险项）；语言/逻辑规模未建立。"掀翻大模型"无跨语言、跨规模实验支撑，对白泽零威胁；唯一可迁移资产是"自回放>外部加练"的方向性。

## 二、训练计划吸收（2.1/2.2 可执行：自回放阶段）

诚实评估：**当前遗忘门已 PASS**（2.0 重训逐字复现 −28.6%，val_ppl 8.71 优于原 9.00〔裁决包 关键发现 1〕），做梦的增益空间不在防遗忘，唯一现实卖点=**替换 replay 数据来源**（现 replay 625k chunks、步数占比 34.8%，单位口径挂催中〔矩阵§11〕）。EXP-DREAM-1 探针（P2，仅进 2.2 空窗，禁止占 2.1 主线）：

1. 生成：以 A 轨基座 T0@866M（val_ppl 5.594〔裁决包 §二′〕，H5 已实证百科词条体生成）解码 ~312k chunks（first-sentence 提示 + temp 1.0 + rep 1.2 + 256/chunk）
2. 过门：mid-band PPL 过滤（5–30）+ SHA256 精确/MD5 聚类 ≤2（复用 d18 verify 门，`d18/verify_d18.py` 改造）+ Decontam8 13-gram + 主理人抽检 50 条
3. 判据：同配方 run——replay 真 chunks 312k + 自生成 312k vs 2.0 基线（8.71 / −28.6%）三重对照（遗忘门+val_ppl）；gate ≥+10% FAIL 即关门归档
4. 风险：Cadence 红线直译——基座事实错误会被放大（H5 已见"小猪历险记制片地区=美国"）；预期收益小，成本采样 2-6h + SFT 6.2h + eval 2h ≈ 1.5 NPU 天

不移植项：Record Store/快慢双记忆（我方无 inference-time 记忆栈）；"训练=推理终身不冻结"（与 checkpoint 冻结流程冲突，仅可在叙事对比句中出现）。

## 三、桌面线 27B Phase A 恢复剧本吸收（Qwen-PA 输入）

Phase A 现状〔收官〕：暂停、双触发器（基建≥14h 会话+SFS 配额+驱动 50 步长跑 G2 闸门；实证需求=C 线 120M 裁断+S1 切换判据）、温恢复 `phase_a_boot.sh` 一条命令、预算 ~44-88h〔矩阵 缺口1〕。四点吸收：

1. **license 人闸（human-gated 落点）**：Phase A 语料含小说 10.6% 且版权未清〔收官§五〕→ 把许可链核查升格为 boot 前正式 human-gate（主理人签核→写入 boot 检查清单），防 14M tok×3ep 白跑
2. **Harness/模型贡献分离**：Qwen-PA 自披露 Harness 单变量 +5.15（71.90→77.05）→ 移植为 S1 判定预注册附页："三臂（尾4/LoRA-only/全层）结果须绑定 harness 配置（v3.8 五层验证+解码参数）上报，任何 Δ 主张声明 harness 是否恒定"。我方先例在案：复读=解码伪影（rep=1.2 使 8/10 死循环→10/10 自然停止）〔裁决包 关键发现 2〕——harness 因素已实证可动门
3. **CARE 奖励工程适用性**：Phase A 是 PPL 消融、无 RL，**不适用**；挂 Phase B（27B planner SFT 冷启动+混合 RL）——按组成功率三档切奖（进度塑形/结果巩固/效率精炼）+成功率先验锚定压制 GRPO 饱和组归一化爆炸；先出 4h 设计稿，RL 基建另计 3-5 天
4. **投资配比与机制替换**：Harness 拿走 5.15 分的教训=恢复顺序先清债（E5 口径对齐、eval v1.3，小时级、门决定性）再上 44-88h 三臂；另 10M-token 长忆（裸 21.99 vs 记忆管理器 67.24，Mem0 仅 48.60）属"机制换"级增益——列入 Phase B 数据计划（d19+ 加记忆工具轨迹类样本），不阻塞 Phase A

**夸张剥离（②"跑赢 GPT-6"）**：77.05 vs 76.84 系自建 MobilePA-Bench，差 0.21，小于其自报 harness 贡献 5.15——裸模型 71.90 对 GPT-6 Astra 76.84 实为落后 ~5 分。剥离结论：该论文价值不在名次而在**口径披露老实**；我方吸收其披露纪律，不引用比武数字。

## 四、我方 d18 闭环 vs Qwen-PA AI-for-Data——差距表

d18 实测〔d18〕：四类（A 物理 150 / B 算术 400 / C 约束 250 / D 拒答 200）定向生成 1000 条，自检通过率 99.4–100%，`verify_d18.py` 回放 1000/0 bad，去重+d15 索引+13-gram 去污染全闸，生成仅 3.7s。

| Qwen-PA 三段 | 我方现状 | 差距 | 最小改进 |
|---|---|---|---|
| AI for Data · 任务构建 | 4 类失败模式手工定型（10 条人工判读触发） | 失败模式挖掘靠人眼、不可规模化 | **d19 自动化**：eval_m4 全量落盘逐条结果→按门失败类型聚类→自动产 d19 配额（复用 gen_d18 seed 池），4-6h |
| AI for Data · 轨迹收集 | 仅 QA 对，无环境轨迹/RL | 无 RL 基建 | 120M 线不做；落点在 Phase B planner |
| AI for Data · 清洗打标 + human-gate | 程序闸全绿+manifest 内含 samples_for_review，无正式人审记录 | human-gate 未制度化 | d18 抽 50 条主理人评审、结果回写 manifest（30min） |
| AI for Training | SFT+replay，优化剂量当量已注册〔矩阵§3①〕 | 无 RL/奖励工程（定位使然） | 不动 |
| AI for Harness | eval 管线 v1.2+zh_v2、解码参数手工修复 | 无"框架-模型共进化"机制 | eval v1.3 `--repetition-penalty` 参数化入 manifest（2h，裁决包议题 4） |

本质一句话：d18 已是"失败驱动定向补数据"的最小闭环（对照 AI-for-Data 核心思想成立），缺 ①挖掘自动化 ②人审制度化 ③轨迹/RL 段（规模线外）。
