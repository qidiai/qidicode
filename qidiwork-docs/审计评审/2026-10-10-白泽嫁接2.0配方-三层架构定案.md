## 二、插件 2.0 训练配方 v1.1（K3 审计修订版）

| 参数 | 1.0（FAILED 版） | 2.0 v1.1 | 修正理由 |
|---|---|---|---|
| 学习率 | 2e-4 | **3e-5 峰值 + warmup 30 步 + cosine 退火至 10%** | K3: 1e-5 矫枉过正（插件"死了但 PASS"白烧窗口）；3e-5=失败值与过火值的合理中点。**不搞动态调 LR**（手写循环加自适应是新风险） |
| 数据量 | d18 1000 条 | **四件装全量作训练池**，本轮按采样子集探针定位 | K3 抓出最大坑：1500 步 × 1.3M 条不自洽——实际只消化 ~1%，"全量灌入"是伪概念 |
| **数据配比** | 无设计 | **加权采样（不复制 upsample）：目标泳道 d20 8-10% + d18 5-8% + d19/对话 3-5% + d17 补余（token 份额）** | K3: 样本数口径目标泳道仅 2% → 插件零效果。**发射前必须打印实际 token 分布，不达标不点火** |
| 步数 | 250（cap） | fla 验证后 1500 全配方；**fla 不生效立刻砍 600 步**；**step500 快照中考 HE，掉 >5pp 即止损** | K3: 两个应急预案写进发射链 + step500 中考（复用已有存档机制，零成本风控） |
| 缺失超参 | 未写 | **batch/grad_accum/seq_len 必须明文**（K3 判 2：没有这三个数无法审计） | 补：batch 4、grad_accum 2、seq 768（沿用 spike 已验证形态），待数据打包后复确认 |
| 代码保镖 | 无 | d20 5k 在场 +gado token 份额 8-10% | 同上 |
| 新语料 | 对话语料（未定密） | **d19 管线脱敏 + 训前抽检报告签字后入池** | K3: 隐私泄露是不可逆伤害，抽检升为一等判据 |

新增判据（K3 补）：
1. **HE 改掉幅制**：插件臂 ≥ 底模臂 −5pp（93.3 有 ±3.3pp 测量噪声，硬卡 93 会被噪声误杀）
2. **style 用 LLM 盲评**：风格锚点 rubric 3 条 × 0/1/2，臂序打乱盲评，分差 ≥0.5/条 算明显胜出
3. **隐私泄露抽检为硬门**：手机号/身份证/客户名抽检，FAIL 即回炉重脱敏
4. **预写归因手册**：若"能力保住但风格没学到"，第一嫌疑人是 attention-only target 模块（r16/qkvo 不动，MLP 扩展留 3.0），第二才是 LR

## 三、判据（预注册 v1.1，考完对账）

1. **HE 掉幅制**：插件臂 ≥ 底模臂 −5pp——"不变笨"硬门（K3 修订：掉幅制替代 93 硬卡）
2. **风格三连 + LLM 盲评**：风格锚点 rubric 3 条 × 0/1/2 分，盲评分差 ≥0.5/条 算明显胜出
3. real_open 开放题 rubric：插件臂 ≥ 底模臂
4. **隐私泄露抽检（新）**：对话语料入池后训前抽检 + 完赛抽检，FAIL 即回炉
5. 任何一项 FAIL → 嫁接 3.0 再降温/给数据，不硬闯

## 四、思考路由设计（K3 审计修订：砍到最简）

1. **关键词门**：直接上线，零成本。默认 `enable_thinking=False`（直答，快 2.6 倍）
2. 触发词扩展（K3 补）：难/复杂/设计/架构/排查/**为什么/对比/分析/推演/证明** 或用户显式要求 → `enable_thinking=True`
3. **0.6B 分类器本轮不做**（多一条部署链多一类误判，关键词门+手动开关覆盖 90% 场景）——列入 3.0 backlog
4. 纪律沉淀（已入终审报告）：**考思考型模型必须关思考**，否则测出的是独白非能力

## 五、下窗口直发命令链（全部已 ready · v1.1 增补）

1. 底模下载（54GB，断点续传，今早实测 8 分钟/113MB/s）
2. `pip install assets/flash_linear_attention-0.5.2-py3-none-any.whl`（零 PyPI）→ **先 20 步 smoke**（新 kernel 交互未知）→ 步速基准：**若步速 >12s/step 当场砍 600 步配方，不硬扛**（K3 风险#2 应急预案）
3. 数据预处理独立 phase：**发射训练前 tokenize + 打包落盘**（不边训边读）+ **打印各泳道实际 token 分布，目标泳道 15-25% 不达标不点火**（K3 必改#2）
4. 发射 train_sft_m4 → 嫁接 2.0 v1.1（配方 = 本文档 §2）——**step500 快照中考，HE 掉 >5pp 即止损**
5. 完赛即刻：A/B 终审重考（预注册判据 §3 + LLM 盲评 + 隐私抽检）→ PASS 则成品，FAIL 回炉

## 六、诚实边界

- 插件 2.0 仍可能不达标（数据配比/温度是经验活）——但 1.0 的失败把失败面从"整个路线"缩小到"配方参数"，属于可迭代收敛
- 对话语料需脱敏+抽取质检（试点流程已有：d19 同款管线），勿直接裸训
- 时间预估：fla 生效后 1500 步 ≈ 2-3.5h；总链 ≈ 1 天内可出 2.0 判决
