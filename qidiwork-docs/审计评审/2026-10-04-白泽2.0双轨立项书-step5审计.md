# 白泽 2.0+1.5 双轨立项书 Step5 交叉终审报告

## ① 自由审查发现（严重度排序）

**S1 阻断级｜杠杆序列时序死锁 + 降级触发线缺失（R-009）**
峰值表 v2 的杠杆②依赖“T2 完赛”，但最坏双臂并发磁盘压力期恰在 T2 未完赛时；若此时触底，杠杆②不可用，而杠杆③（T0 串行）无预注册实测触发线（如“清理后 du 实测 <1.5G”或“运行中空闲 <0.8G”），预案不可执行。且 0.4G 余量全部押在“既有空闲 ~1.0G”估算值上，未实测、未扣 prep scratch 0.5G 与容器/日志开销，面值闭合性不成立。

**S2 高｜双臂错峰写无相位硬联锁（R-007）**
“节奏写死 ≤2k 步”仅限速，未错相。T2/T0 步速不同（T0 可能更快），save 事件会漂移对齐，tmp+final 双份瞬时 +2.8G 仍可能重现。需硬编码步数模偏移（如 T2≡0、T0≡1k mod 2k）写入 v3.2 patch。

**S3 高｜mix v2 源单充分性未验证 + 分词吞吐未入排程（共同盲区）**
github.txt 471MB 过滤 minified/超长行/license 后，有效 token 可能 <120M，难撑 35% 代码配比（140M）；ownthink2 760MB 重复度未知；novels 10% 来源未在库存清单列名。bpe32k 在笔记本 CPU 分词 400M token 按 10-30k tok/s 估需 3.7-11h，是发射临界路径上未估之杆，v1.1 仅将 prep 推至笔记本侧而未给时长。

**S4 中｜120M 激活显存与 batch 降级未预估（共同盲区）**
28M batch~65@seq256 驻留无忧；120M 参数 ×4.3、激活随 hidden×层数×batch 涨，若 batch 被迫降至 32，步数 ×2、时长翻倍至 48-60h，击穿 2-3 天窗口。v1.1 仅说“同步更新口径”，未预演。

**S5 中｜盲评执行协议与弱阳叙事未预注册**
“乱序盲评”未声明评者人数/身份（主理人单人=偏置如何声明）；专利门弱阳区（−1%<Δ≤0）“叙事降档”措辞未预注册，存在事后漂移空间。解码模板逐字节 IM_START/IM_END 一致性亦未纳入盲评偏置控制。

**S6 低｜丁轨切片耗时与 16:00-21:00 块歧义**
清理 1h+切片 2h+丁 2.9h=5.9h；若 16:00-21:00 为硬块则溢出，若为 12h 窗口则容身。切片 2h 为未实测估计。

## ③ 共同盲区清单（GLM-5.3 与立项书均未触碰）

1. **分词吞吐临界路径**：400M token 笔记本 CPU 分词时长未估，直接决定甲轨能否深夜发射。
2. **mix v2 源单充分性**：github 过滤后有效量、ownthink2 重复度、novels 来源均未干跑计数。
3. **120M 激活显存公式**：hidden 放大后激活 ×4-6，batch 降级对步数/时长的冲击未预演。
4. **磁盘面值 vs 实测**：0.4G 余量全部押在“既有空闲 ~1.0G”估算上，未把“发射前 du 实测”设为硬门。
5. **盲评执行者偏置**：未规定评者数量、标签保管、第三人持钥。
6. **弱阳专利措辞**：−1%<Δ≤0 区的文本措辞未预注册，叙事可事后漂移。

## ④ 最终发射门裁决

**GO-with-conditions**

M1-M5 全绿基础上，追加以下条件，未闭合即降级 NO-GO：

| # | 条件 | 验证方式 |
|---|---|---|
| C1 | **磁盘触发线预注册**：发射前 du 实测，清理后空闲 <1.5G 则 T0 串行（不双臂）；运行中空闲 <0.8G 则 T0 仅存 final、T2 暂停 save-every 至 4k。 | 主理人签批前 du -sh 回填 |
| C2 | **错峰相位硬联锁**：T2 save 步数 ≡0 mod 2k，T0 ≡1k mod 2k，写入脚本 v3.2 patch 落档。 | patch diff 审计 |
| C3 | **mix v2 干跑计数**：笔记本侧先跑 10% 抽样分词，外推各源有效 token；github 有效 <120M 则代码配比下调至 30% 并记录偏差。 | 干跑日志 |
| C4 | **120M 显存冒烟**：正式发射前以 batch 32/48/65 各跑 50 步测激活峰值；若 batch<48，步数口径与窗口预算同步更新并重签。 | 冒烟显存日志 |
| C5 | **盲评与弱阳措辞预注册**：评者 ≥2 人（主理人+1 名不知标签协作者），标签第三人保管；弱阳区专利文本固定为“曲线点记录，不主张 loop 收益”。 | 预注册文本入档 |

**结论**：v1.1 修订质量总体合格（数字账闭合、配比/LR 定案合理、门刻度分层清晰），但磁盘预案存在时序死锁与触发线缺失，且分词/显存/源单三项共同盲区可能击穿排程。上述 C1-C5 闭合后，方可发射。
