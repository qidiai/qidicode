## Q1 根因+置信度

**Top1：容量墙 × 欠训墙复合（"规模×数据双欠账"），综合置信度 70%。** 但须按任务分解，笼统并称会误导决策：

1. **代码生成 HE 0/164×4、MBPP 0/974 —— 容量地板单独解释，置信度 90%**。
   文献基线：HumanEval/MBPP 上 GPT-3 300M 级 pass@1 ≈ 0、6.4B 级才 ~3-4%（Chen et al. 2021）；Pythia 160M 同级全程 0。120M 无论 SFT 几代、Chinchilla 最优喂料，代码能力门槛都在 1B 级之外。**这一块不是"病"，是"尺寸"——欠训修复也救不了它**（此点与 K3"容量墙改判欠训墙"分歧，见分歧表）。
2. **中文内容层（03/04 算术胡算、05 桥崩、08 满编）—— 欠训主导 + 长度先验形状错配，容量封顶，置信度 65%**。
   - 欠训：3.3 tok/param vs Chinchilla 20（Hoffmann et al. 2022）/ 现代 20-100。
   - 形状错配实锤（K3 A2）：d15 completion p50=236 字、短答(<60字)仅 14.2%，而 zh 门 10/10 题要求短答——模型长度先验系统性淹没"只输出/≤25字"约束。这是"数据形状"候选的实锤出处，但它解释**形态失败**（满编/超长/复读），不解释**语义失败**（算术/桥接）。
   - 关键证据链：壳对齐回收的是"表达层"（自然停止 2/10→7/10、均长 473→318、01 首胜/04 题面全对/拒答首现）——知识读取部分存在；但内容层纹丝不动（03/04/05/08 原样）+ d18 靶向 26 倍剂量零响应——技能层建不起来，指向基础模型欠账，非 SFT 手艺。
   - 08"满编"新解：rep=1.2 压掉重复填充后无内容可写即直写满编——内容枯竭是欠训症状，非解码症状（解码修复已验证无效于内容）。
   - 07 回文单点命中（d20 弹药）：技能**可注入但极窄**——120M 记得住被点名的模板、泛化不了抽象。复合墙的典型指纹。
3. **次因 ~25%：格式/停止/tokenizer 残余**。与 Opus 五因子口径（格式 30%，壳对齐+rep 已回收 20%、残 10%，手术净 EV 10-15%）基本一致。im_end 5 子词切分 + BPE 边界漂移 + id 级停止失效（K3 A1/T1-T4）是真实缺陷且必修——但壳对齐实验证明它解释"难看"（满编/超长），不解释"不会"（0/164、算术胡算）。
4. **剩余 ~5%：未排查项**——loop 结构 train/infer 一致性（loop 从未在生成指标被测，Q3-δ 顺带核验）。
5. **证据剔除**：遗忘门 −28.6%→−39.1% 全 PASS 按 K3 A3 三层污染（val 分布错配 + replay 直接拟合 eval 分布 + 语料族同源）判不可信，退出根因证据链（不改变结论方向，仅除噪）。

一句话：SFT 三代把 val_ppl 8.71 磨到 7.30 而生成纹丝不动，本身就是"在打磨地基的天花板"——地基（120M × ~400M token）决定了 SFT 手艺的上限。

## Q2 架构裁决

1. **loop 结构：T0 基线走人（生成指标上不再追加任何训练预算），降级为研究资产封存，不销毁**。
   - T2 vs T0 ≈0 差（420M 轻训）——loop 增益在 ppl 层已测为≈0、全尺度≤噪声（K3 B1），生成层证据=0；
   - loop 的理论主场是算法类深度任务（Fan et al. 2024），与本线业务（代码/中文问答）错配；120M 尺度上其理论收益被双墙淹没——在地板下优化结构是零回报；
   - 保留动作：Q3-δ 顺带核验 loop train/infer 步数一致性，若有 mismatch 记入封箱档案（归账完整性，非翻盘理由）。
2. **T3 SourcePool batch+time 双均值污染：可修的实现层缺陷（归约轴选错），非架构硬伤，置信度 60%（未见代码，按 K3"三处污染路径坐实"描述推断）**。
   - 修法方向：per-sequence 沿 time 维在因果掩码内归约，再沿 batch 维聚合；禁止跨样本×跨时间双均值混合。
   - 前提：修复后 ppl+生成双回归；若指标无变化则该路径不在关键路径上，记档即可。三处均属数据流 bug 级 → 皆可修，不构成推翻 T3 设计的理由。
3. **战略层**：A 路线（S5 BGE-M3 0.66MB 嵌入 97.6% + Flash-Next 生成 + 数据弹药管线）为旗舰正确——GGUF 只读不可微调、全参 27B 需 432GB vs 128GB 物理否决（桌面线实锤），自研线不存在第二条生成能力曲线可爬。

## Q3 行动排序（2h55m 窗口 + 3 天）

| # | 行动 | 成本/窗口 | 预期信号 |
|---|---|---|---|
| 1 | **δ 逐 token 分析** | 30min，2h55m 窗口内立即 | ① loop train/infer 步数一致性核验；② im_end 5 子词实际 token 流+边界漂移取证；③ 07 回文命中解剖——若命中串与 d20 模板原样吻合则"弹药=记忆注入、非泛化"实锤；④ 03/04 算术错误模式分类（进位/数位/抄错题）。零训练成本，是 ε 归账表与 γ 设计的输入 |
| 2 | **ε SFT v3 封箱判决**（tokenizer 注册 im_end 单 token + 全量重渲染 + 重训） | ~6.5h；窗口内完成渲染并启动，3 天内收口 | 上行：自然停止 7/10→9+/10、短答达标率升、中文 1.2→1.6±0.15（Opus EV 上限口径）；HE/MBPP 预期仍 0（若非 0=大惊喜，说明格式污染曾掩盖能力）。**必须沿用 Opus 预注册归账表**：tokenizer 份额与 2ep/replay 份额分开记，禁止把 SFT v3 整体收益记在手术账上。同意 Opus"绑进 SFT v3 必做、过门概率 <15%、价值在闭合叙事"判 |
| 3 | **γ T2@866M 同数据对照臂** | 5h；3 天内、排在 ε 之后跑，复用其修好的 tokenizer/壳/数据管线 | 容量 vs 欠训的判决实验（同数据、同 tok 数，唯一变量=参数量）：866M 生成仍 0 → 数据侧（欠训+形状）定案，封箱报告写"3.3 tok/param 欠训"；显著非 0 → 容量墙实锤，封箱报告写"被 120M 参数封顶"。**方法论修正：γ 必须吃 ε 修好的 tokenizer**，否则 866M 生成指标被 im_end 污染、判决不干净（前席执行单未排 γ、K3 判 γ 不吃窗口——本席判：5h 换封箱定性，值） |

- 出局确认：α（2ep 续训=过拟合已证）、β（rep 1.2 重评已完成，不占预算）。
- 并行主线（不占三席名额）：RAG 旗舰按 Opus 执行单 D2-D5 推进（我们容器为主、桌面只做 Flash-Next 推理 API）——训练线三连合计 ~12h 与之不互扰。无论 γ 哪边，3 天后资源答案都指向 A 路线；区别只是自研线"带证据结案"还是"裸结案"。

## 一句话总裁决

生成层不动的第一约束是 120M 容量地板 × 3.3 tok/param 欠训的复合墙（代码 0 分是容量的必然、中文内容不动是欠训主导+形状错配），tokenizer/格式是可修的次因——按 δ→ε→γ 跑完三连判决实验完成归账后，自研线以研究资产身份封箱结案，旗舰交给 A 路线 RAG 栈。
