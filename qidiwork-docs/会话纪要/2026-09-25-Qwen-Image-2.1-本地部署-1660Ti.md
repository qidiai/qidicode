## 四、踩坑记录（按遇到顺序）

1. **hf-mirror HEAD 拿不到真 Content-Length**（302 跳转页 1062 字节）：并行分段脚本须先 `curl -w %{url_effective}` 解析最终 CDN 地址（cas-bridge.xethub.hf.co，国内可直连且 ~23MB/s）再 HEAD 取长度。修正脚本存于 `F:\AI\downloads\dlp.ps1`。
2. **GitHub release 下载被墙**：`release-assets.githubusercontent.com` 完全 0 字节挂起；**gh-proxy.com**（`https://gh-proxy.com/https://github.com/...` 前缀）实测 12MB/s 全速，但忽略 Range（返回 200），分段脚本不适用，单流即可。
3. **city96/ComfyUI-GGUF 对 Qwen3-VL 支持缺失**（仓库停在 2026-01，早于 2.1 发布）：症状为 DiT 前向报 `Given normalized_shape=[4096] ... got input of size [1, 512, 12288]`——TE 缺视觉塔被构建成错误结构、输出 12288 维。**修复：装 pottokao-dotcom/ComfyUI-GGUF-Qwen3VL-TE 补丁节点 + mmproj 放同目录**，重启日志出现 `[GGUF-Qwen3VL-TE] patched` 即生效。
4. **`--force-fp16` 在图灵上病态**：Model Initializing 106s（fp32 仅 36s）后第一步卡 10+ 分钟（GPU 100% 空转），弃用；保持默认 `manual cast: torch.float32`。
5. **PS 5.1 `Set-Content -Encoding UTF8` 写 BOM** → aiohttp 拒收 POST JSON；用 `[System.IO.File]::WriteAllText($p, $raw, [Text.UTF8Encoding]::new($false))`。
6. ComfyUI 0.37 的 workflow 模板不在 templates 包内，在 `comfyui_workflow_templates_json\templates\`（官方 2.1 模板：`image_qwen_image_2_1_t2i.json`）。
7. **abenzerps UC 版 GGUF 自带 `general.architecture='qwen_image21'` 元数据**，city96 `loader.py` 的 `IMG_ARCH_LIST` 白名单没这个值 → `Unexpected architecture type` 拒载。修复：把 `"qwen_image21"` 加进 `IMG_ARCH_LIST`（已改本地文件；**注意该节点更新后此补丁会丢，需重打**——一行改动：IMG_ARCH_LIST 集合追加 `"qwen_image21"`）。带元数据和不带元数据的 GGUF 走不同路径：turbo（无元数据）走补丁节点张量名探测，UC（有元数据）走白名单校验。
