## 八、教训存档（新会话必读）

1. **config 是活文件**——「当时用什么跑的」先问操作者再查 /models 端点，别从静态配置反推（LongCat 误判教训）
2. **PowerShell `&&` 无效/括号崩**——所有 commit/复杂命令用 python subprocess 文件执行；`-Encoding UTF8` 的 Set-Content 会写 BOM（BOM 两门惨案）——**对外部文件一律 python open('wb')**
3. **写文件工具只写 G:\qidicode 工作区**——外部文件先写工作区再 Copy-Item
4. **spawn_subagent 失败会留半成品**——先 py_compile+grep 验尸再续做
5. **评估是结构计数型**——reps 逐位同=确定性复现，禁止解读为统计显著性
6. **数学公式禁令**：管线产出永远 markdown 无 LaTeX（\$\text{}/α β γ 是 LLM 发明幻觉高发区，MATH-DEL 守卫已在三层）
7. **每轮提交=最后一次为准**：换装前想清楚；每天 3 次额度省用
