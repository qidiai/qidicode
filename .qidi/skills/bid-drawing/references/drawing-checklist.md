# 图纸审查清单（合肥 AI 评标实战版）

对照招标文件图纸清单逐项核对，缺失/不规范即扣分。

## 一、图号连续性

| 检查项 | 要求 | 判据 |
|---|---|---|
| 图号序列 | 从图001到图NNN连续 | 缺任何一个图号 = 扣分项 |
| 编号体系 | 通常按专业分：建施/结构/给排水/电气/暖通 | 各专业的图号区间不应交叉 |
| 修订记录 | 变更部位有修订签 | 图纸有设计变更时须附修订章 |

## 二、图幅与比例

| 图类 | 推荐图幅 | 推荐比例 |
|---|---|---|
| 总平面 | A1/A0 | 1:500 / 1:1000 |
| 平面/立面/剖面 | A1/A2 | 1:100 / 1:50 / 1:20 |
| 详图/节点 | A3/A4 | 1:5 / 1:2 / 1:1 |
| 系统图 | A2/A3 | 不标比例（系统示意）|

缺比例 = **扣分项**。图幅过小（如整体总平用 A4）= 被质疑"不够规范"。

## 三、必含元素（每张图）

1. **图框/标题栏**：单位名称、项目名称、图名、图号、比例、日期、设计人/审核人签字栏
2. **指北针**：总平图/平面图必含（除系统图外）
3. **比例尺**：平面图/剖面图必含
4. **图例**：材料/材质/构件符号说明
5. **尺寸标注**：总尺寸→轴线尺寸→细部尺寸三级（不可只注总尺寸）
6. **标高**：地面标高、各层楼面标高、室外标高

## 四、缺图风险清单（常见漏项）

- 总平面布置图
- 基础平面/剖面图
- 主体结构平面/剖面图
-  roof 屋面平面图
-  楼梯详图（各型号至少 1 套）
-  门窗表/门窗详图
-  装饰做法表
-  给排水总平面图 + 系统图 + 节点详图
-  电气总平面图 + 配电系统图 + 照明平面
-  弱电/智能化（如有）
-  安全文明施工专项图（围挡/洗车池/临时道路——合肥项目常考）

## 五、图纸与方案互引

每份施工图中应至少有一处被正文引用（"详见图4-1 XX平面图"），
反之方案描述中应有一处指向具体图纸。单向引用（只有正文写"见图X-X"但无图）
或只有图无引用均视为"编制不完整"。

## 六、合肥 AI 评审特殊注意

1. **图质量影响"针对性"判定**：图模糊、比例缺失、无指北针 → AI 识别为"未针对性编制"
2. **图表数量加成**：中垾坝镇 44 表/12 图 > 徐老家 30 表/9 图 → 图/表丰富度与得分正相关
3. **图号连续是底线**：一旦缺号会被评审直接指出"缺图"，印象分大幅下降
4. **图面整洁度**：CAD 线型混乱/图层命名异常 → 降低"专业性"评分档
