# CAD 绘图行业规范（供投标方参考）

## 图层命名规范（建施）

| 图层前缀 | 含义 | 典型图层 |
|---|---|---|
| `A-WALL` | 墙体 | A-WALL-SOLID（实墙）/A-WALL-HATCH（填充） |
| `A-DOOR` | 门 | A-DOOR-01~12 |
| `A-WIN` | 窗 | A-WIN-01~08 |
| `A-DIM` | 尺寸标注 | A-DIM-H（水平）/A-DIM-V（垂直） |
| `A-TEXT` | 文字标注 | A-TEXT-NOTE |
| `A-TILE` | 瓷砖/饰面 | A-TILE-FLOOR |
| `A-SCALE` | 比例尺/指北针 | A-SCALE-MAP |
| `A-BOUND` | 图框/标题栏 | A-BOUND-FRAME |
| `A-HATCH` | 填充图案 | A-HATCH-CONC/A-HATCH-STEEL |

建筑（建施）、结构（结施）、给排水（水施）、电气（电施）、暖通（暖施）
各专业图图层命名应遵循此规范，混用其他命名（如 `layer1`、`defpoints`）
会让评审认为"不规范"而扣分。

## 图块（Block）推荐清单

施工图必须包含以下图块（用块引用，便于批量修改）：
- 门窗（按系列/尺寸编码）
- 家具/洁具（按类型）
- 配筋符号
- 指北针、比例尺、图例
- 标高符号、轴线端圆

## 线型与线宽

| 线型 | 用途 | 建议线宽 |
|---|---|---|
| 实线（continuous） | 可见轮廓、边界 | 0.5mm（打印后）|
| 虚线（dashed） | 隐藏线、预留孔洞 | 0.25mm |
| 点划线（center） | 轴线、对称线 | 0.25mm |
| 双点划线（divided） | 假想投影 | 0.18mm |
| 粗实线（heavy） | 剖切位置、主要轮廓 | 0.7~1.0mm |

打印输出后线宽须可辨，过细的线（<0.18mm）在扫描后消失是废标风险。

## 图面表达规范

1. **字体**：汉字用仿宋/黑体，字号 ≥3mm（打印尺寸）
2. **标点**：尺寸数字后不加单位（mm 默认），标高加注标高符号（▽）
3. **标注顺序**：外部总尺寸→内部轴尺寸→细部尺寸，三级依次向内
4. **剖面线**：同一剖面不同材料用不同画法（混凝土/砖/土/钢筋）
5. **图面净空**：图框外留白 ≥10mm，不得有溢出裁剪

## DWG 格式

- 推荐使用 AutoCAD 2010 或更新格式（.dwg R18+）
- 投标提交 PDF 时，用 CAD 原生导出（非截图/非虚拟打印），保留可检索性
- 若招标要求提交 CAD 原件，图层和图块须整洁；否则评委会用 AutoCAD 打开检查
- 无数据区的 DWG（Model space 无内容，仅 Layout）是常见隐患——评审用 layout 视图翻图
  发现空白会扣分
