# Construction Plan · 通用施工方案编写

一句话：**输入项目信息（或招标文件/图纸摘要）→ 路由方案类型 → 按国标章节骨架逐章生成 → 图表配套 → 质量门自检 → 输出可编辑方案**。适用于房建、市政、公路、装饰装修、机电安装等常见工程类别，不绑定任何特定地区评标办法。

## 0. 硬性规则

1. **数据一致性优先**：总工期、开竣工日期、里程碑日期在全文所有章节必须完全一致——这是评审专家最先核对的地方。写入任何日期前先与本文件"数据锚点表"核对。
2. **规范引用须现行有效**：引用规范标准写全名+编号（如 GB 50268-2008《给水排水管道工程施工及验收规范》），不确定版本时提示用户确认，禁止编造标准号。
3. **危大工程必须单独成章**：凡辨识出危险性较大的分部分项工程，须在施组中列出清单并注明"另编专项施工方案"；深度≥5m 基坑等超一定规模工程必须写明"组织专家论证"。
4. **禁止空洞套话**：每条措施必须落到"谁、在什么环节、做什么、达到什么标准"，黑名单词见质量门脚本。
5. **工程量/造价类数据必须来自用户提供资料**（清单、图纸、招标文件），缺失时用【待补充：xxx】占位并明确告知用户，禁止凭空编造。

## 1. 方案类型路由（先判断再动笔）

| 用户需求特征 | 产物 | 骨架模板 |
|---|---|---|
| "施工组织设计""施组""投标技术标" | 单位工程施工组织设计 | `templates/shizu-skeleton.md` |
| "基坑/模板/吊装/脚手架/拆除/临时用电…方案"（单一分部分项） | 专项施工方案 | `templates/special-plan-skeleton.md` |
| 方案对象属于危大工程清单（见 `references/special-plan-guide.md`） | 危大工程专项方案 + 提示论证要求 | 同上，并按清单核查规模档次 |

路由判断顺序：①用户明确指定类型 → ②单一分部分项特征 → ③默认按施工组织设计。

## 2. 标准工作流（六步）

```
步骤1 输入收集
  必需：项目名称、工程类别、建设地点、工期、质量/安全目标
  增益：招标文件、工程量清单、图纸摘要、地勘要点、周边环境
  缺失处理：必需项缺失先问用户；增益项缺失用合理占位并标注【待补充】

步骤2 方案类型路由（见第1节）→ 读取对应骨架模板

步骤3 建立数据锚点表（写正文之前先做！）
  开工日期｜竣工日期｜总工期（日历天）｜质量目标｜安全目标｜
  主要里程碑（≥4个）｜关键线路（一句话）｜主要工程量（前5项）
  全文所有数字以此表为唯一来源，后文改动先改表。

步骤4 逐章撰写
  每章执行：本章节要点（references/chapter-standards.md 对应节）
  篇幅建议：总篇幅按用户要求；未指定时单位工程施组 1.5~3 万字。
  针对性要求：每章至少 1 处项目专属内容（具体部位/具体参数/具体
  邻环境），禁止全篇通用描述。

步骤5 图表配套（至少四件套）
  ① 施工进度横道图（开工~竣工，含里程碑竖线）
  ② 施工现场平面布置图（围挡/大门/办公区/加工区/材料堆场/临时水电）
  ③ 项目组织机构图（项目经理→五岗人员→作业班组）
  ④ 劳动力动态曲线或分阶段劳动力表
  生成方式：可用 python matplotlib 按上述四件套绘图（参考
  templates/shizu-skeleton.md 内附录的绘图数据格式），有条件时用
  CAD/办公工具绘制后插图。

步骤6 质量门自检（必跑）
  python scripts/construction_plan_check.py <方案文本.md|txt>
  exit 0 通过；exit 1 存在 error 级问题，逐条修复后复跑。
```

## 3. 单位工程施工组织设计九章速查

| 章 | 名称 | 核心内容 | 最易翻车点 |
|---|---|---|---|
| 1 | 编制依据 | 招标/合同文件、图纸、地勘、现行规范清单 | 引用过期规范 |
| 2 | 工程概况 | 基本信息表、实施范围、地质水文、周边环境、合同边界 | 照抄招标原文无提炼 |
| 3 | 施工部署 | 目标体系、组织机构、任务划分、总体顺序、流水段 | 顺序与进度图矛盾 |
| 4 | 施工进度计划 | 横道图+网络图、里程碑表、关键线路 | 里程碑日期对不上 |
| 5 | 施工准备与资源配置 | 技术/现场准备、劳动力/材料/机械配置表 | 机械进退场与工序脱节 |
| 6 | 主要施工方法 | 按专业分节，工艺流程+操作要点+质量标准 | 大抄规范无针对性 |
| 7 | 质量保证措施 | 体系+六项制度+分部分项控制指标+通病防治 | 指标不量化 |
| 8 | 安全文明与环保 | 责任体系+危大管控+消防+扬尘"六个百分百"+噪声 | 危大漏项 |
| 9 | 主要管理计划 | 进度/质量/安全/环境/成本/成品保护/季节性施工/应急预案 | 应急预案无物资清单 |

每章详细写法、段落结构、字数配比见 `references/chapter-standards.md`。

## 4. 质量门脚本

```bash
python scripts/construction_plan_check.py 方案文本.md
```

检查项与等级：
- **error（阻断）**：必备章节缺失；总工期数字前后矛盾；无进度计划章节
- **warning（提示）**：缺横道图/网络图/平面布置图引用；项目经理/技术负责人/安全员/质量员岗位不全；空洞表述命中（"高度重视""保驾护航""全面提升"等）；提及基坑≥5m/高支模等危大特征但未出现"专家论证"；缺质量/安全目标

修复原则：error 必改；warning 逐条评估，能改则改。

## 5. 与用户资料冲突时

用户资料（招标文件/图纸）与通用规范表述冲突时，**一律以用户资料为准**，并在方案"编制依据"中如实列出。发现用户资料疑似错误（如工期明显不够、工程量矛盾），在对话中提示用户确认，不得擅自改写。

## 6. 输出交付

1. 方案正文（Markdown → 按需转 docx，A4、宋体小四或按用户模板）
2. 数据锚点表（随方案附，供用户核对）
3. 质量门检查结果（通过/修复记录）
4. 交付前最后一步：全文搜索【待补充】，确认所有占位符已处理或已向用户声明。
