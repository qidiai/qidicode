# 施工组织设计章节标准（依据 GB/T 50502-2014）

GB/T 50502-2014《建筑施工组织设计规范》将施工组织设计分为三类：
1. **施工组织总设计**（群体工程/特大型项目，由总承包单位编制）
2. **单位工程施工组织设计**（本技能默认产物）
3. **施工方案**（分部分项工程或专项工程，即"专项施工方案"）

单位工程施工组织设计应包含的基本内容（GB/T 50502 第 4.2.1 条）：工程概况、施工部署、施工进度计划、施工准备与资源配置计划、主要施工方法（方案）、施工现场平面布置、主要施工管理计划。本技能在其基础上扩展为九章实践结构。

---

## 第1章 编制依据

**写什么**（列表即可，不超过1页）：
- 本项目合同/招标文件及澄清答疑（名称+编号）
- 设计文件：施工图纸（各专业分册名）、地勘报告
- 国家/行业/地方现行规范清单（挑 8~15 部与本项目直接相关的，全名+编号）
- 企业内部：质量/环境/职业健康安全管理体系的程序文件

**避坑**：
- 规范必须现行有效。常见过期引用：GB 50300 验评标准已废止改用验收统一标准；混凝土结构验收用 GB 50204-2015。
- 拿不准版本号时写规范名不写年号，并提示用户按最新版核对。

## 第2章 工程概况

**写什么**（1.5~3 页，必须提炼不能照抄）：
1. **基本信息表**（表格）：项目名称、建设地点、建设/设计/监理/施工单位、结构类型、层数/跨度或道路等级/长度、合同工期、质量目标
2. **实施范围与工程界面**：承包范围（哪些做/哪些不做）、与相邻标段或既有设施的界面
3. **工程特点**（3~5 条）：从结构形式、地质水文、周边环境、工期压力中提炼"本项目独有的"特征
4. **周边环境与约束**：邻建构筑物距离、地下管线、交通条件、可用场地
5. **主要工程量表**（前 8~10 项，来自清单）

**避坑**：特征必须具体（"基坑东侧距既有围墙最近 0.8m"而不是"周边环境复杂"）。

## 第3章 施工部署

**写什么**（2~4 页）：
1. **目标体系**：工期/质量/安全/文明/环保目标，逐条量化（工期写"XX 日历天，计划 X 年 X 月 X 日开工、X 年 X 月 X 日竣工"）
2. **项目组织机构**：组织机构图 + 岗位职责表（项目经理、项目技术负责人、施工员、质量员、安全员、材料员、机械员、劳务员、资料员——按项目规模配置）
3. **任务划分与流水段**：分几个区/段，每段包含哪些专业，流水方向
4. **总体施工顺序**：一句话主线（如"先地下后地上、先结构后装饰、先土建后机电"）+ 分阶段顺序描述
5. **主要施工方案的选择**：垂直运输选型（塔吊/施工电梯）、模板体系、脚手架体系、大体积砼/深基坑等关键方案的选择结论与理由

**避坑**：总体顺序必须与第4章进度计划互证——顺序写"先 A 后 B"，进度图上 A 的完成时间必须早于 B 的开始时间。

## 第4章 施工进度计划

**写什么**（2~4 页 + 2 张图）：
1. **总进度计划**：横道图（开工~竣工全周期）+ 双代号网络图（较复杂项目）
2. **里程碑节点表**（表格，6~16 个）：节点名｜计划完成日期｜第 D 日｜验收/控制要求
3. **关键线路**：文字描述关键线路上的工序链
4. **各阶段进度安排**：按基础/主体/装饰/机电等阶段写起止日期与穿插关系
5. **工期保证措施**：组织（进度例会/考核）、技术（穿插施工/新工艺）、资源（储备/多班制）、合同（分供方工期条款）

**避坑**：
- 里程碑日期用程序或表格公式核算"D 日 = 竣工日期 − 里程碑日期 + 1"，禁止心算。
- 春节/雨季等停工窗口必须显式纳入进度图。
- 横道图时间轴与里程碑表必须一一对应。

## 第5章 施工准备与资源配置计划

**写什么**（2~4 页）：
1. **技术准备**：图纸会审、施工方案编制计划（列表：方案名/完成时间/审批人）、测量控制网、试验检验计划
2. **现场准备**：三通一平、临水临电（用水用电量计算或估算表）、临建布置（指向第6章后的平面布置说明或第9章图）
3. **劳动力配置计划**：分工种×分阶段人数表（或动态曲线），峰值期说明
4. **材料配置计划**：主要材料进场批次表（材料/规格/数量/进场时段/使用部位）
5. **机械设备配置计划**：机械名称/规格/数量/进退场时段/用途（进退场时段必须与第4章工序对应）
6. **分包计划**（如有）：拟分包专业及管理要求

**避坑**：
- 机械数量与流水段数自洽（2 个流水段至少 2 台主干机械或说明轮转）。
- 劳动力峰值合计必须等于各工种之和，若"在岗人数"另有口径必须注明是否含管理人员。

## 第6章 主要分部分项工程施工方法

**写什么**（篇幅最大，按项目类别裁剪专业节）：
每个分部分项按四段式写：
1. **工艺流程**（一行箭头链：测量放样→开挖→垫层→…）
2. **操作要点**（逐条，含关键参数：压实度、坍落度、焊缝等级、张拉控制力…）
3. **质量标准**（主控项目+允许偏差，引规范条文）
4. **成品保护与安全要点**（2~4 条）

**裁剪指引**：
- 房建：土方与基坑→地基与基础→主体结构→屋面→装饰装修→机电安装→室外工程
- 市政道路：清表与土方→路基→基层→面层→附属（侧石/人行道）→排水管线→交通设施→照明/绿化
- 装饰装修：拆除与改造→水电管线→基层→面层→收边→清洁
- 通病高发工序（渗漏、开裂、空鼓、沉降）必须出现在质量通病防治（第7章）

**避坑**：每节至少 1 个项目专属参数（来自图纸/清单/地勘），禁止整章照抄规范条文。

## 第7章 质量保证措施

**写什么**（2~3 页）：
1. **质量目标**：合格/优良，一次验收合格率等量化指标
2. **质量管理体系**：责任分工表 + 六项制度（图纸会审与技术交底、材料进场检验与见证取样、工序三检制与交接检、样板引路、隐蔽工程报验、质量例会与考核）
3. **分部分项质量控制指标表**：单位工程｜控制指标（量化：压实度/垂直度/平整度/强度…）｜检验方法
4. **质量通病防治表**：通病｜主要成因｜预防措施（≥5 项，选本项目高发的）
5. **检测/试验计划表**：检测项目｜频率｜方法｜合格标准

**避坑**：指标必须与设计文件一致（如混凝土抗渗等级、压实度分区要求）。

## 第8章 安全文明施工与环境保护措施

**写什么**（3~5 页）：
1. **安全目标与管理体系**：目标量化（杜绝死亡/重伤事故，轻伤率≤X‰）；安全责任矩阵；安全教育培训与交底计划
2. **危险源辨识与风险评价**：LEC 法或风险矩阵，形成重大危险源清单
3. **危大工程管控**：危大清单表（名称｜规模档次｜专项方案/论证要求｜监测方案）；审批流程"编制→审核→技术负责人签→总监审→超规模专家论证"
4. **专项安全措施**：临边洞口、高处作业、临时用电（三级配电两级保护/TN-S）、消防（动火审批/灭火器材布置）、机械安全、有限空间（如适用）
5. **文明施工**：围挡与大门、场容场貌、材料标识、出入口冲洗、扬尘防治措施（覆盖/喷淋/雾炮/在线监测）、噪声与污水控制
6. **应急预案**：组织机构、风险事件处置卡（坍塌/高坠/触电/火灾/管线破坏…）、应急物资清单表、演练计划（量化频次）

**避坑**：应急预案必须含"应急物资清单"和量化演练频次；危大清单不得漏项。

## 第9章 主要施工管理计划

**写什么**（1.5~3 页，可合并精简）：
1. 进度管理计划（纠偏流程：周对比→月考核→偏差 3 日内出纠偏措施）
2. 质量管理计划（与第7章不重复，写管理动作）
3. 成本管理计划（量价分离/限额领料/月度成本分析）
4. 成品保护计划（交叉作业保护措施）
5. 季节性施工保证措施（冬期/雨期/高温，含停工窗口与复工条件）
6. 绿色施工计划（四节一环保目标与措施）
