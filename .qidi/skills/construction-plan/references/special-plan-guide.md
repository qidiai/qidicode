# 危大工程清单与专项施工方案要点

依据《危险性较大的分部分项工程安全管理规定》（住建部令第37号）及建办质〔2018〕31号文。

## 1. 危大工程范围（需编制专项施工方案）

| 类别 | 危大工程（≥此规模编专项方案） |
|---|---|
| 基坑工程 | 开挖深度 ≥3m 的基坑（槽）；<3m 但地质条件/周边环境复杂的 |
| 模板工程 | 各类工具式模板（滑模/爬模/飞模/隧道模）；高支模：搭设高度 ≥5m，或跨度 ≥10m，或施工总荷载 ≥10kN/㎡，或集中线荷载 ≥15kN/m，或高度大于支撑水平投影宽度且相对独立无联系构件的混凝土模板支撑工程 |
| 起重吊装 | 采用非常规起重设备/方法且单件起吊重量 ≥10kN；起重机械安装拆卸 |
| 起重机械安装拆卸 | 塔吊/施工升降机/物料提升机的安装、拆卸、顶升 |
| 脚手架 | 搭设高度 ≥24m 的落地式钢管脚手架；附着式升降脚手架；悬挑式脚手架；高处作业吊篮；卸料平台/操作平台工程；异型脚手架 |
| 拆除工程 | 可能影响行人和交通安全的拆除 |
| 暗挖工程 | 采用矿山法/盾构/顶管等的隧道、洞室 |
| 其他 | 建筑幕墙安装；钢结构/网架安装；人工挖孔桩；水下作业；装配式建筑构件安装；采用新技术/新工艺/新材料/新设备可能影响安全的 |

## 2. 超一定规模危大工程（专项方案需组织专家论证）

| 类别 | 论证门槛 |
|---|---|
| 基坑 | 开挖深度 ≥5m；<5m 但周边环境严重复杂（临近重要建筑/管线/河流） |
| 高支模 | 搭设高度 ≥8m，或跨度 ≥18m，或施工总荷载 ≥15kN/㎡，或集中线荷载 ≥20kN/m |
| 起重吊装 | 单件起吊重量 ≥100kN；起重量 ≥300kN 的起重机械安装拆卸；高度 ≥200m 的内爬起重设备的拆除 |
| 脚手架 | 搭设高度 ≥50m 的落地式钢管脚手架；提升高度 ≥150m 的附着式升降脚手架；分段架体搭设高度 ≥20m 的悬挑式脚手架 |
| 拆除 | 码头/桥梁/高架/烟囱/水塔/拆除中容易引起有毒有害气（液）体或粉尘扩散/易燃易爆事故发生的特殊建（构）筑物 |
| 暗挖 | 采用矿山法/盾构/顶管施工的隧道 |
| 其他 | 施工高度 ≥50m 的建筑幕墙安装工程；跨度 ≥36m 的钢结构安装工程；跨度 ≥60m 的网架/索膜结构安装；开挖深度 ≥16m 的人工挖孔桩；水下作业；重量 ≥1000kN 的大型结构整体顶升/平移/转体 |

## 3. 专项施工方案内容要素（九件套）

1. 工程概况：危大工程概况与特点、平面/立面布置、周边环境
2. 编制依据：法规、规范、图纸、施工组织设计
3. 施工计划：进度安排、材料设备计划、劳动力计划
4. 施工工艺技术：技术参数、工艺流程、施工方法、操作要求、检查要求
5. 施工安全保证措施：组织保障、技术措施、监测监控（监测项目/频率/预警值）
6. 施工管理及作业人员配备和分工
7. 验收要求：验收标准、程序、人员
8. 应急处置措施：应急组织、物资、处置流程
9. 计算书及施工图：必要的安全验算（稳定/承载力/变形）与示意图

## 4. 审批与论证流程（写入方案第7节）

```
施工单位技术部门审核 → 施工单位技术负责人签字盖章
→ 总监理工程师审查签字
→ 【超一定规模】施工单位组织专家论证（专家≥5名，与本工程无利害关系）
→ 按论证报告修改后重新审批 → 交底 → 实施
```

实施要求（一并写入方案）：
- 方案实施前，编制人员或技术负责人向现场管理人员交底；管理人员向作业人员进行安全技术交底并双方签字
- 施工单位应在现场显著位置公告危大工程名称、施工时间、具体责任人员
- 项目专职安全员现场监督；对未按方案施工的责令整改，情节严重的责令停工
- 需验收的危大工程（脚手架/支模架等），施工单位/监理单位组织验收，合格后方可进入下一道工序

## 5. 编写专项方案的参数红线（写错即返工）

- 监测预警值必须写数值（如：桩顶水平位移 ≥10mm 或速率 ≥3mm/d 预警）且与设计文件一致；无设计值时按规范取值并注明出处
- 计算书参数（荷载分项系数、支撑刚度取值）与工况一一对应，禁止直接套用其他项目计算书
- 混凝土支撑/栈桥的拆除时机（达到设计强度百分比）必须写明
- 临时用电方案须含负荷计算与配电系统图；脚手架方案须含立杆间距/步距/连墙件设置
