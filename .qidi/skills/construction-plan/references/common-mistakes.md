# 施工方案常见问题自检清单

评审/审批视角下的高频扣分点。写完方案后逐条自查，或直接跑 `scripts/construction_plan_check.py`。

## A. 数据一致性（最致命）

| # | 问题 | 后果 |
|---|---|---|
| A1 | 总工期在"工程概况"写 300 天、"进度计划"横道图却画了 320 天、"管理计划"又写 290 天 | 专家第一个发现，直接认定编制粗糙 |
| A2 | 里程碑日期与横道图不对应 | 同上 |
| A3 | 开工日期与招标/合同要求不符且未说明 | 视为未响应 |
| A4 | 节假日/停工窗口未从日历天中扣除 | 进度图与文字矛盾 |
| A5 | 工程量与清单/图纸不一致 | 数据真实性存疑 |

## B. 必备内容缺失

| # | 问题 | 补救 |
|---|---|---|
| B1 | 无进度计划图（横道图/网络图） | 必补，纯文字进度不达标 |
| B2 | 无施工平面布置图 | 必补，且应含大门/围挡/办公/加工/堆场/临水临电 |
| B3 | 无劳动力配置 | 必补，分工种×分阶段 |
| B4 | 无机械设备配置或机械与工序不对应 | 补进退场时段 |
| B5 | 组织机构无岗位职责 | 补职责表 |
| B6 | 无应急预案或预案无物资清单 | 补应急处置卡+物资表 |
| B7 | 无质量目标/安全目标量化 | 补数值目标 |

## C. 针对性缺失（通用模板痕迹）

| # | 特征 | 判定 |
|---|---|---|
| C1 | 全文替换项目名后可直接用于任何项目 | 重写特征段 |
| C2 | 施工方法整章照抄规范条文，无一个项目专属参数 | 每节补专属参数 |
| C3 | 工程概况未提炼"工程特点"，只有基本信息堆砌 | 补 3~5 条独有特征 |
| C4 | 平面布置图是示意图（画个方框写"加工区"），无尺寸/位置关系 | 按现场实际重画 |
| C5 | 无周边环境分析（邻建筑/管线/交通） | 补界面表 |

## D. 空洞表述黑名单（出现即扣语言分）

高度重视 / 全面提升 / 保驾护航 / 多措并举 / 扎实推进 / 切实加强 / 全力做好 / 精雕细琢 / 匠心打造 / 赋能 / 抓手（非工程语境）/ 万无一失 / 一流水平 / 世界先进

**替换原则**：每个套话改写为"动作+环节+标准"。例：
- ❌ "高度重视质量管理"
- ✅ "实行工序三检制，每道工序经班组自检、施工员复检、质检员终检合格后方可转序，隐蔽工程提前 48h 报验"

## E. 危大工程相关

| # | 问题 | 要求 |
|---|---|---|
| E1 | 危大工程漏辨识（有 ≥5m 基坑却未列危大清单） | 对照 special-plan-guide.md 清单逐项排查 |
| E2 | 超一定规模工程未提"专家论证" | 必须写明论证安排 |
| E3 | 专项方案无监测方案 | 补监测项目/频率/预警值 |
| E4 | 监测预警值无出处 | 注明设计值或规范依据 |
| E5 | 应急演练未量化 | 写明频次（如每季度 1 次） |

## F. 规范引用

| # | 问题 | 要求 |
|---|---|---|
| F1 | 引用已废止规范 | 写前核对现行版本 |
| F2 | 规范名与编号不符 | 全名+编号一起核对 |
| F3 | 编造标准号 | 宁可写规范名不写号，并提示用户核对 |

## G. 人员与资格

| # | 问题 | 要求 |
|---|---|---|
| G1 | 岗位配置低于项目规模要求 | 按规模配齐"八大员" |
| G2 | 特种作业人员未写持证要求 | 补"持证上岗" |
| G3 | 项目经理/技术负责人资格与招标或合同要求不符 | 以招标/合同为准 |
