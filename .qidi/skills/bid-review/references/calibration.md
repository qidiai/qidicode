## 二、核心结论（反推的评分机制）

1. **合肥AI评标是关键词匹配 + 语义辅助的混合模型**：评分标准原文措辞（"针对性、可行
   性、语言精练度"）在施组中的出现频率直接影响 AI 判定"是否响应评分维度"。
   三维度关键词缺失 = AI 判"未响应评分维度" → 打良好档中下。
2. **微观内容优化对AI评分可能无效甚至负面**（中垾坝镇无索引表/无标注但 78.25 > 徐老家
   71.55）：子节字数/数据来源标注/同字消除等优化不是得分点。
3. **表格图片丰富度可能是独立加成项**：中垾坝镇 44 表/12 图（注意：这是样本相关性归因，不代表堆表能得分；2026-08-31 起改为"按需+实义"原则，数量不设目标，硬堆砌表格没有意义）。
4. **评委主观折扣**：施组 100 分项实际是"评委各成员打分平均值"（招标文件 3.2.2），
   AI 仅辅助评审。村庄改造类小项目评委心理预期低于房建/市政大项目。
   徐老家预估 93-96 实际 71.55，偏差 23 分的根因之一即此。
5. **3 个样本不足以精确反推完整评分模型**——预估分只报区间（75~85 基准），
   下限可至 68。

## 三、v3 预估公式

> ⚠ **本节为历史版本：公式含已废除的评委折扣**。2026-09-01庐江459家评标表实证废除评委折扣
> （见第四节"实证修正"与 SKILL.md Step 5.5/6），现行公式无该项。下文算术保留作校准历史记录；
> 去除评委折扣后的现行参考：巢湖学院 75+3+2+2+2+2=**86** / 中垾坝镇 75+0+2+0+2+0=**79** /
> 徐老家 75+1+0+0+0+0=**76**（A7 2026-09-07 标注）。

```
预估分 = 75 基准
       + 三维度合计≥5次 +3 / 1~4次 +1 / 0次 0
       + 去AI化达标 +2（段内编号<20、高频词密度<0.5‰、无AI术语）
       + 论证句式达标 +2
       + 图表实义达标 +2（2026-08-31 修订：表格图片按需提供、有编号有引用即达标；旧"30~44表/9~12图"为样本相关性归因，不作为数量目标）
       + 四大闭合链全闭合 +2
       + 评委折扣 −6（村庄改造小项目）/ −2（房建/市政大项目）
```

校准验证：巢湖学院 75+3+2+2+2+2−6=80（实测 84.87，残差 +4.9）；
中垾坝镇 75+0+2+0+2+0−6=73（实测 78.25，残差 +5.3）；徐老家 75+1+0+0+0+0−6=70（实测 71.55，残差 +1.6）。
三样本残差均为正 +1.6~+5.3，说明公式整体偏保守，实际结果常好于预估下限——报区间时
以公式值为下限、+5 为上限参考。

## 六、临湖90.15反推（v4方向——第五样本核心结论）

**v3在"定制评分标准+①~⑦镜像响应"项目上完全失效**（低估6.15分+跨分档）。
根因不是渲染/格式，是v3**没有测到A1对照表/因素标注/逐条镜像的实际价值**。

### v4方向（仅列已被临湖实测证实的加分源，不臆测）

1. **去AI化编号规则需前置判断**：当评分标准含定制①~⑦清单时，投标文对应编号=逐条响应→**不扣分**（临湖230个编号+90.15实测，徐老家191个+71.55实测的区别在于：徐老家的编号是AI腔堆砌，临湖的是镜像招标原文）
2. **A1对照表独立加分**：评审因素逐条对照表（第1张表）+每章因素标注——临湖实测~2.5分价值
3. **定制评分标准项目识别**：招标评分标准含项目特定重难点清单（非通用10项）时→**走"逐条响应深度"路径**而非"通用关键词+去AI惩罚"路径

### ⚠ 过滤项（临湖样本中有但**不吸收**的——用户明确说"不要吸收脏数据"）

临湖施组存在小瑕疵（最终版没来得及改），以下特征**不纳入v4**：
- 段内编号230个本身依然超标（虽然本次没被扣分，但徐老家191个+71.55证明堆砌有风险——临湖90.15是因为镜像响应正当性压住了，**不能推广到所有项目**）
- 具体瑕疵清单待逐条确认后再决定哪些值得吸收

**结论：v4修正方向=加前置判断+加A1加分项+项目类型分路径，不加"编号豁免的通用规则"。**

### 入围线实证锚点（2026-09-11 用户修正，优先级高）

用户实证：**临湖 90.15（我方历史最高实测分）仍未入围**——"没进去"，且我方从未进去过；
通用型最高实测 = 高新区 85.78。
- 纪律：技术标审计报告**禁止"大概率进前5/入围概率高"类乐观概率表述**。
- 竞争结论只做二值判定："达线/未达线"；无本场竞品数据时，入围线按 ≥90 量级处理
  （已知实证下限 90.15，每场竞品池不同、线位随场次浮动，只报已知下限不外推）。
- 分数预估照常报区间 + 分布位置（z 值）——预估分与竞争定位分离表述。
