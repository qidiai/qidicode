## 二、核心结论（反推的评分机制）

1. **合肥AI评标是关键词匹配 + 语义辅助的混合模型**：评分标准原文措辞（"针对性、可行
   性、语言精练度"）在施组中的出现频率直接影响 AI 判定"是否响应评分维度"。
   三维度关键词缺失 = AI 判"未响应评分维度" → 打良好档中下。
2. **微观内容优化对AI评分可能无效甚至负面**（中垾坝镇无索引表/无标注但 78.25 > 徐老家
   71.55）：子节字数/数据来源标注/同字消除等优化不是得分点。
3. **表格图片丰富度可能是独立加成项**：中垾坝镇 44 表/12 图。
4. **评委主观折扣**：施组 100 分项实际是"评委各成员打分平均值"（招标文件 3.2.2），
   AI 仅辅助评审。村庄改造类小项目评委心理预期低于房建/市政大项目。
   徐老家预估 93-96 实际 71.55，偏差 23 分的根因之一即此。
5. **3 个样本不足以精确反推完整评分模型**——预估分只报区间（75~85 基准），
   下限可至 68。

## 三、v3 预估公式

```
预估分 = 75 基准
       + 三维度合计≥5次 +3 / 1~4次 +1 / 0次 0
       + 去AI化达标 +2（段内编号<20、高频词密度<0.5‰、无AI术语）
       + 论证句式达标 +2
       + 表格图片密度达标 +2（30~44表/9~12图，图表有编号有引用）
       + 四大闭合链全闭合 +2
       + 评委折扣 −6（村庄改造小项目）/ −2（房建/市政大项目）
```

校准验证：巢湖学院 75+3+2+2+2+2−6=80（实测 84.87，残差 +4.9）；
中垾坝镇 75+0+2+0+2+0−6=73（实测 78.25，残差 +5.3）；徐老家 75+1+0+0+0+0−6=70（实测 71.55，残差 +1.6）。
三样本残差均为正 +1.6~+5.3，说明公式整体偏保守，实际结果常好于预估下限——报区间时
以公式值为下限、+5 为上限参考。
