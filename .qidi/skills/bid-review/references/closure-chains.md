# 四大闭合链校核公式（南岗项目沉淀，2026-09-02）

技术标数据自洽性的四条校核链。任何一条断裂，评审时即被认定为"数据拼凑"。

## 1. 工期闭合链

```
工程量 ÷ 日工效 = 需天数（每工序逐一核算）
平行作业归并后：总需天数 ≤ 可用工期（招标工期）
```

- 每个分项工程都要写出"工程量→班组配置→日工效→需天数"的推导链
- 平行作业关系须与横道图/网络图一致
- 南岗实例：工期 280+20（雨季）=300 天，逐工序核算后闭合

## 2. 设备闭合链

```
台数 × 日产能 × 有效天数 ≥ 工程量
```

- 7 类设备逐一校核（南岗实例：挖机/装载机/自卸车/压路机/搅拌机等）
- 设备退场时间与进度计划对应（避免"设备常驻全场"的浪费表述）
- 设备表 14 处"同"字须改为明确退场值（徐老家实战教训）

## 3. 劳动力闭合链

```
劳动力计划总工日 与 报价人工费反推工日 偏差 ≤ ±5%
```

- 按工种分解：普工/瓦工/木工/钢筋工/水电工等，各工种峰值人数与横道图对应
- 南岗实例：18979 工日，与报价人工费口径核对偏差 ≤±5%
- 注意：技术标评审时报价未开不可核验，表述用"与一览表基准完全一致"，
  不得写"与报价人工费口径一致"（徐老家第六轮教训）

## 4. 物资闭合链

```
清单量 × (1 + 损耗率) = 需用量
```

- 4 类主材（水泥/砂石/钢筋/混凝土等）逐一供需平衡表
- 损耗率取值注明依据（定额或经验值）

## 校核执行方式

审计时写脚本从 DOCX 提取四处数据（进度计划/设备表/劳动力计划/材料计划），
按上述公式反算，输出偏差表。偏差 >±5% 的项标记为"闭合链断裂"。
