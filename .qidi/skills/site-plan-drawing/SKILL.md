# 施工总平面布置图绘制（内蒙古专用）

> **⚠️ 适用范围裁定（2026-09-25，用户指定）**：本技能的"黑白绘制、WPS COM Shapes"规范源自**内蒙古暗标项目**的招标文件要求。各地招标文件对图的要求不同——使用前必须先检索本项目招标文件原文：有黑白/WPS 要求 → 用本技能；**无此要求的（如南谯区项目）→ 用 bid-diagram 技能的彩色专业工程平面图**（matplotlib：分区浅色块+深蓝管线+暖灰道路+图例/指北针/比例尺，参考南谯区 gen_siteplan3.py 彩色实践）。

## 核心原理

用**WPS COM Shapes API**（`doc.Shapes.AddTextbox` / `doc.Shapes.AddLine` / `doc.Shapes.AddShape`）在Word文档中绘制文本框和直线，实现绝对定位的平面图布局。

### 为什么用WPS COM而非python-docx VML

- python-docx的VML `position:absolute`定位锚点在段落上，WPS打开后文本框全部堆叠在段落位置，坐标失效
- WPS COM的`Shapes.AddTextbox`使用页面绝对坐标（磅），WPS打开后位置精确不变
- WPS COM可以直接设置填充透明、边框颜色粗细、字体、对齐等属性

### 布局原则

1. **外框矩形**：用`AddShape(msoShapeRectangle)`画大外框，占A4纸80%区域
2. **设施文本框**：每个设施用`AddTextbox`画独立小方框，分布在页面四周（左设施区/右设施区/中间道路区/底部图例区）
3. **道路区域**：三条道路纵向排列在中间，每条路用一个标题文本框+一个施工区域文本框
4. **围挡线**：用`AddLine`在道路两侧画竖线模拟围挡
5. **临时水电**：用小文本框（0.8cm×0.8cm）散布在道路两侧
6. **项目部独立**：项目部办公区放在左侧，独立于道路施工区域
7. **图例**：底部用文本框排列符号+说明

## 使用步骤

1. 准备道路信息：`[(道路名称, 全长, 特殊说明), ...]`
2. 准备设施清单：`[(设施名称, 规格, 位置区域), ...]`
3. 调用 `scripts/generate_plan.py` 生成docx文件
4. 用WPS打开检查布局，手动微调位置

## 关键参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 页面方向 | A4横向 | 29.7×21cm |
| 页边距 | 四边 | 2cm |
| 外框 | 占可用区域80% | 左1cm 上5cm 宽25.7cm 高14cm |
| 文本框边框 | 0.5磅黑色 | Line.Weight=0.5 |
| 围挡线 | 1磅黑色 | Line.Weight=1.0 |
| 文本框字体 | 五号宋体(9pt) | Font.Size=9 |
| 道路标题字体 | 四号宋体(10pt) | Font.Size=10 |
| 文本框填充 | 无（透明） | Fill.Visible=False |

## 暗标格式要求（内蒙古暗标项目要求——非通用）

- 图表标题：黑色四号宋体(14pt)，居中
- 图表内文字：黑色五号宋体(9-10pt)
- 所有边框：0.5磅黑色单实线
- 颜色仅使用黑色（内蒙古要求；无黑白要求的项目禁用本技能，改用彩色工程图）
- WPS Word黑白绘制（内蒙古要求）
- 图表居中放置

## 常见陷阱

1. **不要用python-docx VML画文本框**：VML的`position:absolute`锚点在段落上，WPS打开后坐标全部偏移
2. **必须用WPS COM的Shapes API**：`AddTextbox`/`AddLine`/`AddShape`使用页面绝对坐标
3. **文本框填充必须设为透明**：`shape.Fill.Visible = False`，否则会遮挡其他元素
4. **项目部不能和施工区域放一起**：要独立放在道路之外的区域
5. **临时水电用小方块**：0.8cm×0.8cm的文本框，散布在道路两侧
6. **坐标单位是磅**：用`word.CentimetersToPoints()`转换
