# 踩坑记录

## 方案1：python-docx单元格底色填充（废弃）

用`w:shd fill="000000"`填充表格单元格模拟横道条/区域块。

**问题**：暗标评审中底色填充被判废标（招标文件要求"图表均采用WPS Word文字处理软件黑白绘制"，底色填充不属于"绘制"）。

## 方案2：python-docx VML shape文本框（废弃）

用`<w:pict><v:shape style="position:absolute;left:Xpt;top:Ypt">`在段落中插入VML文本框。

**问题**：VML的`position:absolute`锚点在所在段落上，不是页面绝对坐标。python-docx每个文本框添加在不同段落上，导致所有文本框堆叠在各自段落位置。WPS打开后全部挤在页面左上角，坐标完全失效。

## 方案3：python-docx表格模拟布局（部分可用）

用嵌套表格+合并单元格模拟平面图布局。

**问题**：
- 看起来像表格不像平面图
- 设施文字堆在一个单元格里太多
- 项目部和施工区域在同一个表格行里，给人"项目部建在施工路上"的感觉
- 无法画独立直线（围挡线、道路线）

## 方案4：WPS COM Shapes API（最终方案）

用`win32com.client`调用Word/WPS的`doc.Shapes.AddTextbox`/`AddLine`/`AddShape`。

**优势**：
- 页面绝对坐标（磅），WPS打开后位置精确不变
- 可以画独立文本框、直线、矩形
- 可以设置填充透明、边框、字体、对齐
- 与示例图（附表示例图.doc）的画法完全一致（VML shape + line）

**关键细节**：
- 坐标单位是磅，用`word.CentimetersToPoints(cm)`转换
- 文本框填充必须设为透明：`shape.Fill.Visible = False`
- 文本框边框：`shape.Line.ForeColor.RGB = 0`（黑色），`shape.Line.Weight = 0.5`（0.5磅）
- 文字居中：`tf.TextRange.ParagraphFormat.Alignment = 2`
- 垂直居中：`tf.VerticalAnchor = 3`
- 直线：`doc.Shapes.AddLine(x1, y1, x2, y2)`
- 矩形：`doc.Shapes.AddShape(1, left, top, width, height)`（msoShapeRectangle=1）

## 布局经验

1. **项目部独立**：不能和施工区域放一起，要放在道路之外的左侧/右上角
2. **设施分散**：每个设施用独立小文本框，不要把多个设施堆在一个文本框里
3. **临时水电小方块**：用0.8cm×0.8cm的小文本框，散布在道路两侧
4. **围挡线**：用1磅直线画在道路两侧
5. **图例在底部**：符号+说明成对排列
6. **指北针**：右下角"N↑"
