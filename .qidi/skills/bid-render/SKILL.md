# 标书效果图生成技能

## 产物呈现（强制）

本技能任何产出交付文件（docx/xlsx/pptx/pdf/png 等）的任务：

1. 文件落盘成功后立即登记：
   `python ~/.qidi/skills/office-artifact/scripts/card.py add <产物路径> --skill bid-render --note <一句话说明>`
2. 任务最终回复前必须输出卡片总览：
   `python ~/.qidi/skills/office-artifact/scripts/card.py show`
3. 不许只回一行文件路径就结束；卡片失败则降级为 Markdown 表格列出全部产物。


用 image_gen 工具生成标书插图。标书配图的特殊要求：**工程感真实、无虚构元素、
与方案数据一致**（塔吊数量、场地布置与平面图对应）。

## 使用前判断

优先级判断该图是否适合 AI 生成：
1. **数据类图表**（横道图/网络图/S曲线/直方图）→ 转用 `/bid-diagram`（matplotlib，
   数据精确可复算，AI 画图数字不可信）
2. **示意类/效果类**（竣工效果、工艺示意、场景氛围）→ 本技能 image_gen
3. **需精确标注尺寸的图**（平面布置图）→ 不用 AI（尺寸会乱），用绘图工具

## 提示词模板库

### 1. 竣工效果示意图

```

晴天，现代工程摄影风格，写实，高清细节，中国[地区]建筑风格
```

实例：
```
美丽乡村人居环境整治项目竣工效果航拍图，村内沥青道路整洁，两侧绿化带和太阳能路灯，
农房外立面焕新，雨污分流管网入地，小型净化槽设施隐蔽于绿化带，远处田野与村庄和谐相融，
晴天，现代工程摄影风格，写实
```

## 生成规范

1. **aspect_ratio 选择**：航拍全景 16:9；工艺剖面 4:3 或 3:2；对比图 1:1
2. **规模数字入提示词**：塔吊 3 台、板房 2 层等数量必须写进 prompt，
   与设备闭合链/平面布置图一致
3. **风格锚定**：加"写实/工程摄影/工程制图"风格词，避免卡通/艺术化
4. **中文文字**：AI 生成图中的中文文字会乱码——图内不要求文字，
   插入 Word 后用题注补图号图题
5. **多图一致性**：同一项目的系列图在提示词开头复用同一段场景描述，
   保证风格统一
6. 每图生成后检查：设施数量是否与方案一致、有无明显失真（悬空结构/多余肢体等），
   失真图重生成
7. 效果图属示意图性质，图题加"示意"字样（"图5-2 净化槽安装工艺示意图"），
   避免与竣工照片混淆引发废标风险

## 插入标书流程

1. image_gen 生成 → 保存 PNG
2. 检查与方案数据一致性
3. md2docx 前在 Markdown 中引用 `![图5-2 xxx示意图](path.png)`
4. 或手动插入 Word：统一缩放宽度 15cm，加题注"图5-2 xxx示意图"
5. 正文须有"见图5-2"引用 + 50~100 字读图分析
