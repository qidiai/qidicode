# 标书方案编写技能（bid-creation SOP）

按八步流程产出一份锚定评分点、数据闭合、去AI化的投标技术标。
写作铁律：**每章结论段显式出现"针对性、可行性、语言精练度"三维度关键词**
（合肥AI评标是关键词匹配+语义辅助混合模型，关键词缺失=被判未响应评分维度）。

## Step 1：关键要求提取

从招标文件（PDF/DOCX，用 PyMuPDF/python-docx 解析）提取五类硬性要求：

| 类别 | 提取内容 |
|---|---|
| 资质 | 施工总承包等级、安全生产许可证、专项资质 |
| 人员 | 项目经理（注册建造师等级+B证）、技术负责人职称、八大员配置 |
| 业绩 | 近N年同类工程个数/面积/金额门槛 |
| 财务 | 审计报告、注册资本、营收要求 |
| 设备 | 主要机械设备种类与数量要求 |

提取不到的项标记 `[待补：xxx]`，不杜撰。本地规则 + 语义提取双通道交叉验证。

## Step 2：章节规划（锚定评分点）

1. 解析招标文件评分办法，列出：评分项 → 分值 → 对应章节映射表
2. 解析评分档次（优/良/一般/差对应分数区间），**写作对标最高档描述**
3. 字数标准：**高分值章节（≥10分）正文 ≥5000 字；其他章节 ≥3000 字；
   每个子节（x.y 级）≥200 字**（AI按子节级评估内容深度）
4. 章节顺序：首页直接进入实质内容；技术标 1.1 项目基本情况只写项目本身
   （名称/编号/招标人/资金/地点/工期/质量/类型+针对性描述），
   **不堆砌招标文件的审批机关/评标办法/资质要求**（属商务文件内容，占篇幅无分）

## Step 3：地域特征适配

按项目所在地加载地域施工特征（完整词典见 references/regional-features.md）：
东北→冬季施工、南方→雨季台风、高原→健康保障、城区→扬尘噪声、沿海→防腐蚀等。
服务类/采购类标书不加地域施工特征。

## Step 4：四大闭合链数据构造（数据自洽是评审硬伤检查点）

写方案时按公式**正向构造**数据（公式详见 references/closure-chains.md）：

```
工期：工程量 ÷ 日工效 = 需天数（逐工序核算，平行归并后 ≤ 招标工期）
设备：台数 × 日产能 × 有效天数 ≥ 工程量（设备表写明确退场值，禁用"同上"）
劳动力：各工种工日合计 与 报价人工费口径偏差 ≤ ±5%
        （表述用"与一览表基准完全一致"，技术标评审时报价未开不可核验）
物资：清单量 × (1 + 损耗率) = 需用量（损耗率注明定额依据）
```

工程量数据一律以已标价工程量清单为准，**不加"（数据来源：xxx清单）"标注**
（AI评审可自行调取清单核验，标注无得分贡献只占篇幅）。

## Step 5：写作规范（得分关键）

### 必须做
- 每章结论段至少各 1 次显式出现：`针对性`、`可行性`、`语言精练度`
- 编制原则段直接引用招标文件评分标准原文"针对性、可行性、语言精练度"
- 多用"结合本工程特点"引出针对性描述（巢湖学院样本 8 次，84.87 分）
- 表格 30~44 个、插图 9~12 张（有图号图题、被正文引用）
- 数据用论证句式嵌入："净化工序需 45 天，系按净化槽 2 套×日处理能力核算"
- 每图配 50~100 字读图分析（不能"以图代论"裸贴）

### 严禁做（去AI化红线）
- 段内编号（段中塞 ①②③/(1)(2) 式罗列）——全文 <20 处
- "确保/落实/保证"高频堆砌——密度 <0.5‰
- AI 术语零出现：赋能/抓手/闭环/颗粒度/底层逻辑/组合拳/打法
- 通用模板句："值得注意的是""综上所述"开头堆叠、空泛口号段
- 段落结构：论点+数据+工艺细节，3~5 句自然段，不用"首先其次最后"机械连接

## Step 6：占位符系统

需投标人线下确认的信息用占位符标记，生成后醒目提醒用户替换：

- `[资质占位符：安全生产许可证编号]`
- `[人员占位符：项目经理注册建造师证书编号]`
- `[业绩占位符：近3年同类工程合同]`
- `[财务占位符：2025年度审计报告]`

**暗标模式不插入任何占位符和投标人信息**（暗标暴露身份=废标）。

## Step 7：商务标结构（如需）

投标函 + 商务偏离表 + 技术偏离表 + 评分索引表 + 资格审查索引表。
评分索引表格式：评分项 → 分值 → 对应章节 → 响应状态（完全响应/正偏离）。

## Step 8：Word 导出

用 `scripts/md2docx.py`（Markdown → DOCX）：

```bash
python scripts/md2docx.py 方案.md --project "XX项目施工总承包" \
    --bidder "XX建设工程有限公司" -o 投标文件.docx
```

- 封面：项目名 26pt 居中 + 副标题"投标文件"18pt + 投标人 + 日期 + TOC 自动目录域
- **加粗标记解析**：`**xx**` 必须拆分为多个 run 设置 bold（直接塞入会显示星号，
  实测踩坑）
- 表格：三线表样式，长表 `cantSplit` 防跨页断行
- 页数控制：超页红线用 WPS COM `ComputeStatistics(2)` 实测（Word COM 本机不稳）

## 自检

成稿后运行 `/bid-review` 技能审计（关键词命中/去AI化/闭合链/预估分），
预估 ≥80 再交付。
