# 第一章 项目概况与编制依据

## 1.1 项目基本情况

本工程为某新区综合服务楼施工总承包项目，建筑面积 26500 平方米，地上十二层、地下一层，工期 360 日历天。工程地质条件为粉质黏土夹粉砂层，地下水位埋深 2.3 米，基坑开挖需同步实施降水与支护。

| 项目 | 内容 | 指标 |
|---|---|---|
| 建筑面积 | 地上十二层、地下一层 | 26500 平方米 |
| 合同工期 | 日历天 | 360 天 |
| 质量目标 | 一次验收合格 | 合格 |

**针对性**：结合本工程地下室单层面积大、桩基密集的特点，桩基与土方按分区流水组织，避免基坑暴露时间过长。

![总平面布置示意](media/fig-normal.png)

### 1.1.1 建设条件

场地北侧为既有道路，施工围挡按城市扬尘管控要求设置；东侧临近居民区，噪声敏感，混凝土浇筑安排在昼间进行。施工用水由市政管网接入，用电按 630kVA 报装。

### 1.1.2 场地移交与临建

临建按办公区、生活区、加工区三区分离布置，加工区靠近塔吊覆盖范围，减少二次搬运。
