# 地域施工特征词典（13 类，bid-creation P1 功能）

按项目所在地匹配地域特征，写入"结合本工程特点"的针对性章节。
服务类/采购类标书不加地域施工特征。

| 地域类型 | 关键词 | 施工特征要点 |
|---|---|---|
| 东北严寒 | 沈阳/长春/哈尔滨/辽宁/吉林/黑龙江 | 冬季施工方案（负温混凝土/暖棚法）、冻土开挖、供暖养护、冬歇期排产 |
| 华北平原 | 北京/天津/河北/山东/河南 | 春季风沙防护、夏季高温错峰、冬期施工、地下水位控制 |
| 西北干旱 | 西安/兰州/乌鲁木齐/宁夏/青海 | 缺水养护（养护剂替代洒水）、大风防尘、昼夜温差大温差裂缝控制 |
| 南方多雨 | 广州/深圳/杭州/福建/江西/湖南 | 雨季施工（基坑排水/防涝）、台风季窗口期排产、梅雨期防潮 |
| 沿海台风 | 上海/宁波/温州/厦门/青岛/海南 | 台风应急预案、抗风加固、盐雾防腐蚀（钢筋阻锈/涂层）、桩基船机作业 |
| 高原高海拔 | 西藏/青海/四川甘孜/云贵高原 | 氧气保障/健康监护、低温低气压设备降效折减、人员轮换 |
| 城市市区 | 合肥城区/南京/武汉主城 | 扬尘噪声控制（围挡喷淋/夜间施工许可）、交通导改、周边建筑保护、渣土外运 |
| 丘陵山区 | 皖南/浙西/福建山区 | 高边坡支护、山洪防治、便道修筑、材料二次转运 |
| 软土地区 | 天津滨海/上海/长三角平原 | 深基坑降水与支护、桩基施工、沉降监测、地下管线探测 |
| 岩溶地区 | 贵州/广西/云南东部 | 溶洞探测与处理、桩基持力层验证、突泥涌水预案 |
| 地震高烈度 | 川滇/青藏地震带 | 抗震构造措施、减隔震安装、材料延性要求 |
| 湿热地区 | 重庆/武汉/长沙/南昌 | 高温高湿季节性施工、混凝土缓凝、钢结构防锈、防暑降温 |
| 北方滨海盐渍 | 环渤海盐渍土区 | 盐渍土处理（换填/隔断层）、防腐蚀水泥、返盐期避让 |

## 使用方式

1. 从招标文件提取项目所在地（市/县级）
2. 按上表匹配 1~2 个地域类型（如"合肥城区"→城市市区；"宁波"→沿海台风+南方多雨）
3. 将对应施工特征写入针对性章节，句式模板：

> 结合本工程地处XX的气候与地质特点，针对性采取以下措施：（具体措施，
> 每条带工艺参数和验收标准）

每条特征须落到**具体工艺参数**（如"负温混凝土掺防冻剂掺量≤水泥用量5%，
入模温度≥5℃"），不写空泛原则句。
