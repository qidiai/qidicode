# 四大闭合链构造公式（写入方案的数据骨架）

写方案时**正向构造**数据（评审时反算校核，任何一条断裂即判"数据拼凑"）。

## 1. 工期闭合链

```
工程量 ÷ 日工效 = 需天数（每工序逐一核算）
平行作业归并后：总需天数 ≤ 可用工期（招标工期）
```

写作要点：
- 每个分项工程写出"工程量→班组配置→日工效→需天数"完整推导链
- 工序逻辑关系须与横道图/网络图完全一致（用 /bid-diagram 生成图表后互查）
- 南岗实例：总工期 280+20（雨季预留）=300 天

## 2. 设备闭合链

```
台数 × 日产能 × 有效天数 ≥ 工程量
```

写作要点：
- 7 类主要设备逐一列表校核（挖机/装载机/自卸车/压路机/搅拌机等）
- 设备表退场时间与进度计划对应，**写明确退场值，禁用"同"**（徐老家 14 处"同"实战教训）
- 富余系数 1.1~1.2 留产能余量

## 3. 劳动力闭合链

```
劳动力计划总工日 与 报价人工费反推工日 偏差 ≤ ±5%
```

写作要点：
- 按工种分解：普工/瓦工/木工/钢筋工/水电工，各工种峰值人数与横道图阶段对应
- 劳动力动态曲线（需求直方图）与进度计划同频
- 表述用"**与一览表基准完全一致**"，不写"与报价人工费口径一致"
  （技术标评审时报价未开，不可核验——徐老家第六轮教训）
- 南岗实例：18979 工日，偏差 ≤±5% 闭合

## 4. 物资闭合链

```
清单量 × (1 + 损耗率) = 需用量
```

写作要点：
- 4 类以上主材（水泥/砂石/钢筋/混凝土等）逐一供需平衡表
- 损耗率注明依据（定额编号或经验值+理由）
- 进场计划与场地堆放能力和进度计划对应

## 数据一致性铁律

1. 工程量数据一律以**已标价工程量清单**为准，不加"（数据来源：xxx）"标注
2. 同一数据在方案/劳动力计划/设备表/材料计划中**完全一致**（跨章复制后逐一回查）
3. 用 `/bid-review` 的 Step 5 做交叉核查
