# 横道线方案踩坑记录

## 已废弃的方案

### 1. matplotlib 生成图片插入 Word
- **问题**：招标文件要求"WPS Word黑白绘制"，插入图片不符合要求
- **结论**：废弃

### 2. 单元格底色填充
- **问题**：暗标评审中底色填充会被判废标
- **结论**：废弃

### 3. WPS COM AddLine 画线
- **问题**：线条被单元格竖线截断
- **结论**：废弃

### 4. WPS COM AddShape 画连续矩形
- **问题**：`Information(7)`（wdVerticalPositionRelativeToPage）返回值不可靠，横道线Y坐标全部错位
  - 表头行top=59.5，但第1条工序top=49.5（比表头还小，不可能）
  - 即使保存关闭后重新打开，Information仍返回异常值
  - 手动计算Y坐标也不可靠，因为页边距、标题行高、表头行高都会影响偏移
- **结论**：废弃

### 5. 单元格底边框（不设零边距）
- **问题**：横道线在单元格底部，像下划线，不在行内居中
- **结论**：废弃

### 6. 段落顶部边框（不设零边距）
- **问题**：横道线在单元格交界处有间隙，不连续
- **结论**：废弃

## 最终方案：段落顶部边框 + 单元格零边距 + 段落缩放

### 原理

1. **连续性**：单元格左右边距设为0（`tcMar.left/right = 0`），相邻段落的顶部边框在单元格交界处无缝衔接
2. **居中**：段前间距 = (行高 - 边框厚度) / 2，行距设为极小值1pt
3. **精确定位**：段落左缩进 = 开始天数分数 × 列宽twips，右缩进 = (1 - 结束天数分数) × 列宽twips

### 关键XML

```xml
<!-- 单元格零边距 -->
<w:tcMar>
  <w:left w:w="0" w:type="dxa"/>
  <w:right w:w="0" w:type="dxa"/>
</w:tcMar>

<!-- 段落顶部边框 2pt (sz=16, 单位1/8pt) -->
<w:pBdr>
  <w:top w:val="single" w:sz="16" w:space="0" w:color="000000"/>
</w:pBdr>

<!-- 段落间距：行距1pt，段前=行高/2 -->
<w:spacing w:line="20" w:lineRule="exact" w:before="283" w:after="0"/>

<!-- 段落缩进 -->
<w:ind w:left="283" w:leftChars="0" w:right="0" w:rightChars="0"/>
```

### 注意事项

- 行高改变后，段前间距必须重新计算
- 行距必须设为固定值（exact），不能用自动行距
- 设置`cantSplit`属性防止行跨页
- WPS COM `Information`属性在Kwps.Application中不可靠，不要依赖它获取坐标
