# 合肥投标报价分析（bid-price-analysis）

## 定位与分工
- **本技能**：报得巧——报价合不合规、会不会触发异常低价、能不能进推荐序列、报多少合适
- **bid-cost-analysis**：算得准——成本分析表与清单控制价逐项核对（成本侧）
- 两者配合：先用 cost-analysis 得到成本价，再用本技能判定报价区间安全性

## 规则基线（2026-09-01 从合肥N1招标文件提取，示范文本 202601 版）
1. **异常低价线**（评标办法前附表 3.6.3）：低于任一线 → 异常低价评审（澄清+成本测算+承诺），未通过 → 否决
   - ① 通过报价文件初评审投标人报价算术平均 × 50%
   - ② 通过报价文件初评审投标人次低报价 × 50%
   - ③ 最高投标限价 × 45%
   - ④ 评委专业判断（不可量化 → 以自家成本测算价做覆盖率提示）
   - 结果保留 2 位小数（第三位四舍五入）
2. **推荐规则**（附件2）：S=进入报价评审家数；S 奇数取第 (S+1)/2 高、偶数取第 S/2 高为门槛；评标价不低于门槛者按低到高推荐；同价技术分高优先
3. **入围**（附件1）：技术详细评审前 5 名（不足 5 家全入围）进入报价评审
4. **报价浮动率** L=(1-中标价/最高限价)×100%（工程变更单价按限价子目同比下浮 L）
5. **报价响应性**：安全文明费/安责险/工日单价≥最低工资折算/暂列金暂估价不可改/增值税/总人工费不明显过低/缺漏≤3%
6. **报价不参与评分**（技术评分合理价格法）——目标是合规 + 进推荐序列，不是分最大化

## 输入
必须：最高投标限价、拟投标报价、竞对报价样本（≥1家，通过初评审口径）
可选：自家成本测算价（④风险提示）、竞对历史中标价/控制价比值样本≥3（启用蒙特卡洛）

## 工作流程
1. 从招标文件提取：控制价（3.2.4/最高投标限价）、异常低价条款、推荐规则、计税方法、
   暂列金/暂估价、工期（合肥 N1 实测：控制价 10996081.66 元、一般计税、300 日历天）
2. 运行 `scripts/hefei_price.py` 规则层：
   `python hefei_price.py --control 10996081.66 --my 9850000 --competitors 9900000,10150000,10400000 --project N1 --out 报告.md`
3. 竞对历史样本≥3 时追加蒙特卡洛（`monte_carlo_optimal`，复用标书软件 pricing_model）
4. 输出报告四段：异常低价四线判定 / 推荐排序模拟 / 响应性清单 / 浮动率
5. 若触发任一线 → 提示必须准备的澄清材料清单；④线给出成本覆盖结论

## 重要规则
1. **不估算**：异常低价线全部由真实报价样本计算，竞对样本缺失时明确标注"假设值"
2. **④线不量化**：评委专业判断不可模拟，只给成本覆盖率提示，不虚构"安全区"
3. **报价不评分**：禁止套用基准价扣分模型给 N1 类项目"算最优分"——只算排序与合规
4. **缺漏口径**：多报金额不得抵销缺漏金额，缺漏按最高限价相应数据计算，占比≤3% 且不影响排序
5. **竞价样本口径**：竞对报价=通过报价文件初步评审的报价（含本家）
6. 模型文件 `pricing_model.py` 复制自标书软件（logger 已桩化，可独立运行）
