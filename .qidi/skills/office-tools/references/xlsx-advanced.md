# Excel 高级操作：公式与财务模型规范

## 核心规则：公式优先

所有计算值必须是 Excel 公式，不要用 Python 算好后硬编码：

```python
# ✓ 正确
ws['B10'] = '=SUM(B2:B9)'
ws['C5'] = '=(C4-C2)/C2'
ws['D20'] = '=AVERAGE(D2:D19)'

# ✗ 错误
ws['B10'] = df['Sales'].sum()
ws['C5'] = 0.15
```

## 公式重算

openpyxl 写入的公式是字符串，无缓存值。用 recalc.py 填充：

```bash
python scripts/recalc.py output.xlsx [timeout_seconds]
```

输出 JSON 结构：
```json
{
  "status": "success|errors_found",
  "total_errors": 0,
  "total_formulas": 42,
  "error_summary": {}
}
```

常见错误: `#REF!` (引用错误), `#DIV/0!` (除零), `#VALUE!` (类型错误), `#NAME?` (未知函数)。

## 财务模型颜色规范

| 元素 | RGB | 含义 |
|------|-----|------|
| 蓝色文字 | #0000FF | 硬编码输入/场景切换 |
| 黑色文字 | #000000 | 公式和计算值 |
| 绿色文字 | #008000 | 跨表引用 |
| 红色文字 | #FF0000 | 外部链接 |
| 黄色填充 | #FFFF00 | 关键假设/需审核单元格 |

## 数字格式

| 数据类型 | 格式代码 | 示例 |
|----------|---------|------|
| 年份 | (纯文本) | 2024 |
| 货币 | `$#,##0` | $1,250 |
| 零值 | `$#,##0;($#,##0);-` | - |
| 百分比 | `0.0%` | 12.5% |
| 倍数 | `0.0x` | 3.2x |
| 负数 | `(#,##0)` | (123) |

## 公式最佳实践

- 集中假设: 增长率/利润率/倍数放标记的假设单元格，公式引用而非内嵌
  - `=B5*(1+$B$6)` ✓
  - `=B5*1.05` ✗
- 无循环引用（除非显式设计并注释）
- 硬编码值加注释: 来源、页码、URL
- 验证清单: 检查 2-3 个引用、确认列映射、处理 NaN、测试边缘值

## pandas + openpyxl 协作

| 场景 | 工具 |
|------|------|
| 批量数据处理 | pandas |
| 单元格格式/公式/图表 | openpyxl |
| 只读大文件 | openpyxl read_only=True |
| 只写大文件 | openpyxl write_only=True |

注意: `data_only=True` 读取缓存值，但保存后会永久删除所有公式。
