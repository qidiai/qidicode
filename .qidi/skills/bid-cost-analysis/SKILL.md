# 工程投标成本分析审查

## 产物呈现（强制）

本技能任何产出交付文件（docx/xlsx/pptx/pdf/png 等）的任务：

1. 文件落盘成功后立即登记：
   `python ~/.qidi/skills/office-artifact/scripts/card.py add <产物路径> --skill bid-cost-analysis --note <一句话说明>`
2. 任务最终回复前必须输出卡片总览：
   `python ~/.qidi/skills/office-artifact/scripts/card.py show`
3. 不许只回一行文件路径就结束；卡片失败则降级为 Markdown 表格列出全部产物。


对比成本分析表（Excel）与清单控制价（xls/RAR）和招标文件（PDF），逐项核对真实数据，修正后输出新Excel。

## 前置条件

用户须提供以下文件（至少2个）：
1. **成本分析表**：.xlsx 文件，含汇总表+各分项分析表
2. **清单控制价**：.rar/.zip 压缩包，含控制价汇总表+各楼栋分部分项清单
3. **招标文件**：.pdf 文件，含控制价总额/暂列金额/暂估价/评标办法/工期等

## 工作流程

### 第一步：读取成本分析表

用 openpyxl 读取所有sheet（data_only=False读公式，data_only=True读计算值）：
- 汇总表：提取各费用项金额、控制价、下浮率、利润率
- 各分项表（人工/材料/机械/专业分包/措施费/间接费/管理人员工资）：提取工程量、单价、合价

### 第二步：读取招标文件关键参数

用 pdfplumber 提取PDF文本，重点查找：
- 控制价总额（3.2.4条 最高投标限价）
- 暂列金额、暂估价金额
- 计税方法（一般计税/简易计税）
- 工期要求（与定额工期对比，判断是否需赶工措施费）
- 评标办法（异常低价线、下浮率计算规则）
- 招标代理费等其他费用

### 第三步：解压并读取清单控制价

```python
import xlrd  # .xls格式必须用xlrd
```

读取顺序：
1. **控制价汇总表**（D.1表）：各单项工程金额、暂估价、不可竞争费
2. **各单位工程汇总表**（D.3表）：分部分项/措施项目费/不可竞争费/其他项目/安责险/增值税
3. **分部分项清单**（E.1表）：逐条提取材料名称、单位、工程量、综合单价、合价
4. **措施项目清单**（附录F）：赶工措施费、智慧工地建设费等费率
5. **不可竞争项目清单**（附录G）：环境保护/文明施工/安全施工/临时设施费率
6. **编制说明**：赶工要求、智慧工地等级、暂定工程量等

### 第四步：逐项对比

按以下清单逐条核对，**只对比真实数据，不估算**：

| 对比项 | 成本分析来源 | 清单来源 | 判定规则 |
|--------|-----------|---------|---------|
| 材料工程量 | 材料费分析表D列 | 清单分部分项E.1表汇总 | 量差>5%标记问题 |
| 材料单价 | 材料费分析表E列 | 清单综合单价（注意含人工机械，非纯材料价） | 不直接对比，用项目所在地信息价 |
| 安全文明施工费 | 措施费分析表 | 清单不可竞争费合计 | 金额差>5%标记问题 |
| 措施项目费 | 措施费分析表 | 清单措施项目费合计 | 逐项检查是否漏算 |
| 安责险 | 汇总表 | 清单安责险合计 | 检查是否漏算 |
| 暂列金额 | 汇总表 | 清单其他项目-暂列金额 | 金额必须一致 |
| 暂估价 | 汇总表 | 清单其他项目-专业工程暂估价 | 金额必须一致 |
| 五险一金 | 管理人员工资表E列 | 应为工资×30% | 检查E列是否为空 |
| 赶工措施费 | 措施费分析表 | 清单措施项目-JC-08 | 编制说明有赶工要求则必查 |

### 第五步：修正Excel

用 openpyxl 修改（保留公式，只改数值/增行）：
- 材料费分析表：替换工程量为清单实际值
- 措施费分析表：补充漏算项（注意合并单元格需先unmerge再处理）
- 管理人员工资表：填入五险一金
- 汇总表：更新规费等固定值
- 另存为新文件，不覆盖原件

### 第六步：计算修正后成本

```python
# 投标报价 = 变动费用×1.15 + 固定费用
# 变动费用：人工+材料+机械+专业分包+措施费+间接费+管理人员工资
# 固定费用：公司管理费+其他+规费+税金+预留金
```

输出：修正后成本价、投标报价、利润、利润率、下浮率（对照控制价）。

## 重要规则

1. **不估算**：所有数据从源文件提取，不用经验值
2. **材料单价按项目所在地**：不同地区信息价不同，不套用全国均价
3. **业务概念先确认**：暂估价=其他费用、招标代理费=中标人成本，不要标为错误
4. **清单综合单价≠材料单价**：综合单价含人工+机械+管理+利润，材料单价是纯材料
5. **xlrd读.xls**：openpyxl不支持老格式.xls，必须用xlrd
6. **合并单元格**：openpyxl写入前需unmerge，写入后重新merge
