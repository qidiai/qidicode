# 危大工程专项检查清单

> 定位依据：危大工程是安全监管重点，也是合肥 AI 评审实践中权重最高的部分。
> AI（青天大模型）会结合招标文件、工程量清单及图纸综合判定——识别不到位或方案不符直接丢分。
> 典型废分案例：超 12 米深基坑放坡条件不足却写"放坡开挖"（违背招标文件/图纸硬约束）。

## 检查一：危大工程识别清单（表格化）

方案中必须有一张**危大工程识别清单表**，逐项明确：

| 列 | 要求 | 常见错误 |
|---|---|---|
| 危大工程类别 | 按住建部 37 号令口径逐类排查（见下方范围表） | 只列 2~3 类，模板化照抄 |
| 对应本项目部位 | 写明具体楼栋/区域/工序（如"3#楼东侧基坑，开挖深度 4.2m"） | 只写类别不写部位 |
| 规模参数 | 基坑深度/搭设高度/跨度/荷载等量化值 | 无数字，"深度较大"式描述 |
| 是否超规模 | 对照建办质〔2018〕31 号论证标准逐项判"是/否" | 全部写"否"未论证 |
| 是否需专家论证 | 超规模项必须"是" | 超规模却写"否" |
| 对应专项方案编号/章节 | 与方案后续章节联动 | 清单与正文脱节 |

### 危大工程范围速查（住建部 37 号令，须逐类对照本项目排查）

- [ ] 基坑工程：开挖深度 ≥3m，或 <3m 但地质条件/周边环境复杂
- [ ] 模板工程及支撑体系：搭设高度 ≥5m；跨度 ≥10m；施工总荷载 ≥10kN/㎡；集中线荷载 ≥15kN/m；高度大于支撑水平投影宽度且相对独立无联系构件的混凝土模板支撑
- [ ] 起重吊装及安装拆卸工程：采用非常规起重设备、方法，且单件起吊重量 ≥10kN 的起重吊装工程
- [ ] 脚手架工程：搭设高度 ≥24m 的落地式钢管脚手架；附着式升降脚手架；悬挑式脚手架；高处作业吊篮；卸料平台（操作平台）
- [ ] 拆除工程：可能影响行人/交通/电力/通讯或其他建（构）筑物安全的
- [ ] 暗挖工程：采用矿山法/盾构/顶管等
- [ ] 其他：建筑幕墙安装、钢结构网架安装、人工挖孔桩、水下作业、装配式建筑构件安装等

### 超规模需专家论证判据速查（建办质〔2018〕31 号附件 2 口径）

- 基坑：开挖深度 ≥5m
- 模板支撑：搭设高度 ≥8m；跨度 ≥18m；总荷载 ≥15kN/㎡；线荷载 ≥20kN/m
- 起重吊装（安装拆卸）：采用非常规起重设备、方法，且单件起吊重量 ≥100kN；起重量 ≥300kN，或搭设总高度 ≥200m 的起重机械安装拆卸工程
- 脚手架：搭设高度 ≥50m 落地式；提升高度 ≥150m 附着式；架体高度 ≥20m 悬挑式
- 拆除：码头/桥梁/高架/烟囱/水塔/拆除中易燃易爆等特殊环境
- 暗挖：全部

## 检查二：针对性方案（逐危大项）

- [ ] 每个危大项均有独立小节（不得多条合并一笔带过）
- [ ] 支护/搭设方式**依据地勘报告或图纸选定**，并写明选择理由（如"③层粉质黏土含水率较高，采用放坡 + 土钉墙组合支护而非纯放坡"）
- [ ] 方式与招标文件/图纸硬约束一致（核对：基坑深度 > 放坡条件允许值时，禁止出现"放坡开挖"）
- [ ] 关键控制参数量化：坑边堆载限值（kN/㎡）、监测点位布设（间距/数量）、预警值与报警值（mm/速率）、降水/止水参数
- [ ] 监测频次与巡检安排明确
- [ ] 与清单联动：危大相关措施项目（如支护桩/降水井）在措施清单中有对应

## 检查三：保障措施闭环

- [ ] 专项施工方案编制/审批流程（施工单位技术负责人审批 → 总监理工程师审查 → 超规模项专家论证通过后方可实施）
- [ ] 交底层级（项目技术负责人 → 施工员 → 班组，书面签字）
- [ ] 现场责任人/专职安全员逐项落实到人（写职务+职责，不写无姓代号）
- [ ] 验收程序（搭设完成后验收挂牌，未验收不得使用）
- [ ] 出险处置方式（报警/疏散/抢险组织链与应急预案章节呼应）
- [ ] 危大工程公示牌/清单动态管理制度提及

## 与 AI 评审相关的加分写法

1. 识别清单表**放正文**（AI 只读文本，表格内文字可被解析），不要只做成图片
2. 每个危大项小节标题含危大类别关键词（"深基坑工程专项方案"），便于 AI 匹配评分点
3. "是否超规模/是否专家论证"两列的判定结论在正文中再次出现（关键信息 ≥2 次原则）
4. 避免纯模板句（"严格遵守规范要求施工"无效），必须带本项目参数

## 审核判定分级

| 级别 | 触发条件 |
|---|---|
| 🔴 P0 必改 | 有 ≥3m 基坑/≥5m 支撑等明确危大项，但方案无识别清单表；或超规模项未提专家论证；或支护方式与图纸/地勘矛盾（如超 12 米深基坑写放坡） |
| 🟡 P1 应改 | 有清单但无规模参数列/无是否超规模判定；危大项方案无量化控制参数（预警值/监测点缺失） |
| 🟢 合格 | 清单完整+逐项针对性方案+审批论证交底闭环 |
