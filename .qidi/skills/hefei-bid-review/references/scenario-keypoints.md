# 分题材要点库（scenario-keypoints）

> 素材来源：合肥 AI 评审领域实战案例复盘沉淀（2026-09，共 8 个案例）。
> 用途：编写/审核特定题材技术标时，先查本库该题材的"AI 评审核心权重"与"隐形扣分点"，再按通用流程执行。
> 注意：以下"权重/核心模块"结论为一线实操经验观察，非官方评分标准文件，使用时须以本项目招标文件评审因素原文为最终依据。

## 各题材速查索引

| 题材 | 核心打分模块（勿轻） | 隐形扣分点（勿漏） |
|---|---|---|
| 水利防洪/河道治理 | 防渗体系/堤身压渗/汛期导流/高边坡防护 | 重绿化配套、轻核心工艺（本末倒置） |

## 一、水利防洪/河道治理（案例：某河道防洪治理项目，AI 评审体系）

**AI 核心打分模块（占比高）**：
1. 防渗体系
2. 堤身压渗
3. 汛期导流
4. 高边坡防护

**权重观察**：常规绿化等配套内容权重低。**常见误区**：同行本末倒置，重附属内容轻核心工艺 → 被扣分。

**四条编织技巧（贴合水利 AI 识别规则）**：
1. 分区段模板化架构（按桩号/堤段分区组织方案）
2. 量化管控参数（核心工艺全带数字）
3. 工期-设备-人力全链条逻辑闭环
4. 专项风险处置形成闭环（汛期抢险单独成节）

## 二、高标准农田（合并要点）

**八要素结构（章节框架）**：针对性 → 土地平整 → 灌溉排水 → 田间道路 → 土壤改良 → 进度计划 → 人员设备配套 → 后期管护。

各要素要点：
- **土地平整**：写明田面坡度、平整精度、耕作层剥离厚度（根底质量是关键）
- **灌溉排水**：依水源条件选渠灌或喷灌；渠道防渗、管网布设、排灌分离明确
- **田间道路**：主次分明，满足农机通行 + 经济性论证
- **土壤改良**：对症下药（不同土壤问题不同措施，禁止通用表述）
- **进度计划**：**考虑农时**——避开农忙和雨季（这是农田项目特有约束）
- **人员设备配套**：与实际操作相符
- **后期管护**（⭐ 隐形扣分点）：**招标文件未提及也要写**——AR 会按行业规范和政策要求核查。三个必答问题：①责任主体是谁 ②管护内容和周期（渠道清淤/管网维护/道路修补）③经费来源。禁止口号式写法。"管比建更重要"，施组应包含"建"和"管"两部分。

**八条对应关系（横向自检）**：灌溉方式 ↔ 水源条件、进度 ↔ 设备、工序 ↔ 农时等——每条对应关系在方案中要能找到两侧呼应。

**重难点章数据强校验**：AI（青天大模型）会**比对重难点里出现的工程量与工程概况数据**——无数据或比对不上直接扣分。重难点必须：从项目特征出发 + 列具体工程量数据 + 给应对措施（呼应 section-writing-templates.md 三段式）。

## 三、市政道路（案例解析）

**AI 评审三大重点**（市政道路与房建/农田逻辑不同，重点在地下）：

1. **管线迁改保护方案**（须详尽）：项目范围、管线类型、管径、埋深、产权单位、施工顺序、保护措施、应急预案——八项缺一不可
2. **交通导改方案**（须可行）：分段方案、围挡布置、临时交通标志标线、交通疏导、人员配置
3. **地下管网工序逻辑**：施工进度计划、劳动力配置、材料计划三者互核（横纵闭环，呼应 audit-checklist.md 第七节）

## 四、农村公路（AI 入围案例复盘）

**核心写法**：
1. **政策衔接**：开篇结合农村公路提升行动、革命老区基础设施扶持政策表述（AI 识别政策响应）
2. **评分索引表**：制作评分点索引表，对应招标要求（9 村分段施工、道路宽度等），避免 AI 判漏项
3. **摒弃套话 + 量化分散施工**：表格量化各村落分段施工、机械调配、错峰施工、村内围挡防护长度；避免"施工方案完整"等虚词；保障村民日常通行不中断
4. **贴合村情制定重难点**：聚焦多村分散施工、田间老路衔接、村民通行困扰、老区生态防护；每个风险配套施工分区、交通疏导、农田保护的具体参数（拉开技术标分差）
5. **全内容逻辑闭环防数值矛盾**：9 村组同步/错峰施工的劳动力、混凝土用料、设备计划与道路总长、分段工期一一对应（AI 自动校准数值矛盾）

## 五、医院类公建（案例：某基层专科医院综合楼项目，人工评审，总工期 828 天，造价约 1.2 亿）

> 注意：该项目为**传统人工评审、无 AI 打分**——其方案逻辑可迁移至 AI 评审项目的编写阶段。

**四条核心经验**：
1. **目录贴合评分规则**：按评分细则组织目录，分专业拆分为三级目录，便于专家快速找到得分点（人工评审"评委 8 分钟翻找"逻辑；AI 评审同样利于因素匹配）
2. **紧扣院区专属需求**：细化病患分流、隔音防腐等医疗专项内容，配材料参数与分段施工时序（多专业交叉、专项工艺极多）
3. **长工期数据自洽**：828 天级长工期项目，各阶段工期、工序、人员机械配置必须逻辑自洽（时间跨度越大越容易前后矛盾）
4. **医疗专项危大工程单独闭环**：风险预判、分步施工、监测管控全流程（呼应 weida-gongcheng-checklist.md 三步走）

## 使用方法（审核时）

1. 判定项目题材 → 查本库对应条目
2. 核对"核心打分模块"是否在方案中占足篇幅与深度（均衡性 + 针对性双查）
3. 核对"隐形扣分点"是否踩雷（特别是"招标文件没提也要写"类：农田后期管护）
4. 题材特有横向对应关系（如农田八条对应、市政管网三表互核）并入 audit-checklist.md 第七节闭环检查
5. 本库结论与招标文件评审因素冲突时，**以招标文件为准**并在审核报告标注
