# 分章节写作模板库（措施类章节）

> 依据：合肥 AI 评审实战方法论沉淀（2026-09）。
> 核心原则：**重控制轻态度**——AI 对通用表述"符合标准"但不予计分；措施必须可验证、可落地。
> 适用章节：质量措施 / 工期措施 / 劳动力配置 / 重难点分析。与 `audit-checklist.md` 3.2 节逐因素检查配合使用。

## 通用公式（所有措施类章节）

```
措施段 = 触发场景(本项目具体部位/工况) + 具体做法(工艺/参数) + 执行标准(规范号+量化合格线) + 责任人(岗位) + 超差处置(返工/整改流程)
```

**态度词黑名单**（出现即标记"重态度轻控制"，正文应替换为具体做法）：
加强管理 / 严格控制 / 高度重视 / 做好养护 / 精心施工 / 强化监督 / 严格落实 / 切实保障 / 做到最好 / 认真贯彻

---

## 一、质量保障措施 —— 五步法

对每个关键工序的质量控制段落，按五问展开：

| 步骤 | 回答的问题 | 写法要求 |
|---|---|---|
| 1. 明管控点 | 该工序最易出问题的环节是什么 | 从本项目工序出发（如涂料开裂/环氧空鼓/防水渗漏），每章 3~6 个管控点 |
| 2. 定合格标准 | 合格线是多少、依据什么规范 | 写数值+规范号 |
| 3. 讲管控手段 | 用什么工艺/方法保住标准 | 具体工艺动作 |
| 4. 确验收主体 | 谁来验（自检/互检/专检的责任岗位） | 写岗位职务，如"质检员会同监理旁站" |
| 5. 制偏差方案 | 超差后怎么办 | 返工/整改流程+判定人 |

### 正反例对照（混凝土工程）

❌ **无效写法**（通用表述，AI 不计分）：
> "混凝土浇筑时加强振捣控制，做好养护工作，确保混凝土质量。"

✅ **有效写法**（量化+可验证）：
> "大体积混凝土采用分层连续浇筑，每层厚度≤500mm；入模温度控制在 5-30℃；浇筑完成 12 小时内覆盖保温保湿养护≥14 天；每 200㎡ 布置一个测温点（经验参考值，实施时按 GB50496 分区测试要求细化），测温频率升降温期每 2h 一次，内外温差＞25℃ 即启动保温覆盖应急措施（质量员负责记录，超出报警值报项目总工核定处置）。"

### 套用示例骨架（供编写时填空）

```
【XX工程】质量控制（对应评审因素N）
管控点：XX 工序的 XX 环节（本项目 3#楼/屋面/地下室等具体部位易出现 XX 问题）
标准：XX≤XX（依据《XX规范》GBXXXX-XXXX 第 X.X 条）
手段：采用 XX 工艺，控制 XX 参数在 XX 范围
验收：班组自检→质检员专检→监理旁站验收，形成记录
超差：出现 XX 情况立即停止作业，报项目总工，按 XX 流程返工/加固处理后重新验收
```

## 二、工期保障措施 —— 三要素

工期章节的可信度来自"依据来源"，三个要素缺一不可：

| 要素 | 写法要求 |
|---|---|
| 1. 关键线路 | 明确哪条线路为关键线路、天数分解；与网络图/横道图一致 |
| 2. 节点承诺 | 分栋/分区/分阶段交付节点写成承诺表（日期+交付物），呼应招标文件节点要求 |
| 3. 风险应对 | 对关键线路上的风险（天气/供货/交叉作业）逐项给应对预案（资源调配/延长工时/夜间施工），并说明赶工不压缩关键工序养护时间 |

### 正反例对照

❌ 无效："我公司实力雄厚，一定能按期完工，确保工期目标实现。"

✅ 有效："本项目关键线路为：基础施工(25d)→主体结构(40d)→装饰装修(35d)→机电调试(15d)，合计 115d ≤ 总工期 120d，富余 5d 作为雨季及材料检验缓冲。若主体阶段遇连续降雨延误，启动夜间施工（19:00-23:00，已含照明与降噪措施）将关键工序追回，节点承诺见下表（表 X，对应评审因素N）。"

## 三、劳动力配置 —— 三维度验证

| 维度 | 验证公式/要求 |
|---|---|
| 1. 人数从工作量推算 | 各工种人数 × 工作天数 × 人均工效 ≥ 该工序工程量（产量验证）；工作量、劳动力配置计划表、进度计划表三者相互匹配 |
| 2. 工种与施工内容对应 | 专项工种必须与实际施工内容一一对应（有防水作业就必须有防水工；有幕墙就有打胶工），避免"配置不合理"判定 |
| 3. 劳动力曲线与进度同步 | 曲线随施工节奏有起伏（基础/主体/装饰阶段人数不同）；高峰人数留储备系数（建议 1.1~1.2），并写明高峰期食宿/交通/工资保障 |

### 写作骨架

```
劳动力配置计划（对应评审因素N）
1. 依据工程量反推：XX 工程量 ÷ 人均工效 XX ÷ 计划工天 XX = XX 人，取 XX 人（含 XX% 富余）
2. 分阶段配工表（基础/主体/装饰各阶段各工种人数），与横道图节点一一对应
3. 劳动力动态曲线描述：高峰期第 X 周 XX 人，储备系数 1.1X
4. 特种作业人员持证清单（电工/焊工/架子工等，证书类型+数量）
5. 高峰期保障：食宿安排/交通组织/工资支付保障
```

## 四、重难点分析 —— 三段式

**先辨析：重点 ≠ 难点**
- 重点 = 决定成败的事项（回答"项目上什么最重要"）
- 难点 = 跨不过去会导致失败的坎（回答"什么事情最难搞"）
- 两者有时相同有时不同，**必须分开阐述**，不得混写一段

**三段式结构**（每个重难点条目）：

```
1. 说明重难点：XX（写本项目具体条件，如"3#楼紧邻在用教学楼，净距仅 8m"）
2. 分析影响：若处理不当将导致 XX 后果（工期/质量/安全/周边影响）
3. 解决方案：采取 XX 措施（工艺+参数+资源），确保 XX
```

❌ 无效（正确的废话）："本项目工期紧、任务重、施工难度大，我公司将高度重视、精心组织。"

✅ 有效："难点：3#楼东侧基坑开挖深度 4.2m，紧邻在用教学楼（净距 8m），地下水位高。
影响：支护失效将危及教学楼基础安全并导致停工，预计直接损失 15 天以上。
对策：采用放坡+土钉墙组合支护（依据地勘报告③层粉质黏土参数），坡顶 2m 范围内禁止堆载，2m 范围外限载 ≤10kN/㎡，布设 6 个变形监测点、预警值 20mm/报警值 30mm，监测频次 1 次/天，变形超报警值立即回填反压并启动专家论证的应急加固预案。"

## 五、自查清单（写完措施章节后过一遍）

- [ ] 每个措施段是否回答了"谁来做、怎么做、做到什么数值、超差怎么办"
- [ ] 是否存在态度词黑名单词汇（有则替换为具体做法）
- [ ] 参数是否可追溯到清单/图纸/规范（禁止拍脑袋编造，见 data-verification-guide.md）
- [ ] 措施与本项目条件绑定（含楼栋/部位/工况名称），换一个项目名即失效的段落才算有针对性
- [ ] 数值与方案其他表数据一致（交叉比对，见 audit-checklist.md 第七节）
