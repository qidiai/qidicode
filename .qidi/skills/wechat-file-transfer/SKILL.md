# 微信文件传输助手 — PC→手机 传文件作战手册

**场景**：用户在外，要把本机文件即时送到手机微信。原理：PC 微信向「文件传输助手」发文件，手机微信秒同步。

## 前置检查（30 秒）

```powershell
Get-Process Weixin,WeChatAppEx -ErrorAction SilentlyContinue | Select Name,Id,MainWindowTitle
```
- 主进程 `Weixin`，窗口标题 `微信`（`WeChatAppEx` 是内嵌浏览器子进程，忽略）
- 无进程 → 微信没开，需要用户先登录，停止并告知
- 确认无 DPI 缩放陷阱：`windows-mcp__DisplayInventory`，scale 必须 1.0（本机 1920x1080 已确认）

## 核心事实（微信 4.x 的坑）

1. **自绘 UI，无障碍树是空的**：UIA/Snapshot 拿不到微信内部元素，只能「截图 + 视觉子代理读图 + 坐标点击」
2. **窗口内相对坐标**（769 宽窗口实测，用 GetWindowRect 把窗口原点 (wx,wy) 换算成屏幕坐标）：
   - 搜索框中心：`(280, 52)` → 屏幕 `(wx+280, wy+52)`
   - 消息输入区中心：`(525, 955)`
   - 工具栏：表情 `(397,989)`、**文件夹按钮 `(439,989)`**、截图 `(481,989)`、发送按钮 `(697,989)`
   - 会话列表行高约 60~72px
3. **会话列表是活的**：新消息到达会实时重排行序——陈旧截图里的行坐标一律作废

## 标准流程

### 第 1 步：文件进剪贴板
```powershell
Set-Clipboard -Path (Resolve-Path <文件>).Path
@(Get-Clipboard -Format FileDropList).Count   # 必须 ≥1，验证
```

### 第 2 步：窗口定位与截图
用 PowerShell 脚本（SetForegroundWindow 聚焦 + GetWindowRect 取矩形 + CopyFromScreen 截窗口区存 PNG），
模板见本技能目录 `capture_wechat.ps1`。每次要"看"微信状态就重跑一次。

### 第 3 步：打开文件传输助手（唯一安全路径）
1. 点搜索框：屏幕 `(wx+280, wy+52)`
2. 用 `windows-mcp__Type` 输入 `文件传输助手`，**press_enter 必须为 false**
3. **等 3 秒**（结果面板渲染），重截图
4. 此时左侧列表变成**静态搜索结果**（不会重排）。裁左侧栏（约 300x480），派视觉子代理
   （model=agnes-2.5-flash）定位「文件传输助手」行的顶边/底边/中心
5. 点该行中心
6. **发送前强制验证**：重截图，视觉确认右侧面板顶部标题逐字 = `文件传输助手`，才准进第 4 步

### 第 4 步：发送（两条路线，A 快 B 稳）
- **路线 A（粘贴）**：点输入区中心 `(wx+525, wy+955)` → `Shortcut ctrl+v` → 截图确认文件预览出现
  （发送按钮变绿）→ `Shortcut enter` 发送 → 截图终验（绿色文件消息出现在消息区、无红色感叹号）
- **路线 B（原生对话框，最稳）**：点工具栏文件夹按钮 `(wx+439, wy+989)` → 弹出的是
  **Windows 原生文件对话框（标准控件，不靠视觉）** → 在文件名框输入完整路径 → Enter →
  预览出现 → 点发送按钮 `(wx+697, wy+989)` → 终验同上

### 第 5 步：终验
截图 + 视觉确认：标题=文件传输助手、消息区最新一条是目标文件、无失败标志。

## ⚠️ 三条事故级铁律（每条都有真实事故）

1. **绝不在搜索框输入状态下按回车**。微信 4.x 会把回车误路由到当前打开的聊天，把搜索词
   当消息发出去（2026-10-15 事故：把"文件传输助手"五个字发进了一个 158 人群，撤回窗口
   2 分钟已过，无法挽回）。搜索结果靠**点击**，永远不靠回车。
2. **绝不信陈旧截图里的列表行坐标**。列表因新消息实时重排，点击前必须重新搜索过滤成
   静态结果并重新截图定位。
3. **视觉子代理的坐标必须自检**：
   - 报告的坐标不得超出图片尺寸（超出=幻觉，直接作废重问）
   - 用裁剪图问坐标时，把偏移量写进提示词并抽查一次换算（2026-10-15 事故：视觉忘了 60px
     裁剪偏移，点击差了一整行）

## 误发应急

群消息撤回窗口只有 **2 分钟**：立即对误发消息右键 → 撤回。超时只能坦白告知用户。
