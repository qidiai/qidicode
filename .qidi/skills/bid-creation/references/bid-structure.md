# 投标文件结构参考

实际结构必须以当次招标文件"投标文件格式"章节为准。

## 施工项目投标文件目录

```
第一部分 商务技术标
  一、投标函
  二、法定代表人身份证明
  三、授权委托书
  四、技术方案/服务方案
    4.1 评分索引表
    4.2 工程概况
    4.3 施工总体部署
    4.4 施工方案及技术措施
    4.5 质量保证措施
    4.6 安全施工措施
    4.7 文明施工措施
    4.8 施工团队及人员配置
    4.9 材料选用与技术参数
    4.10 施工进度计划（横道图/网络图）
    4.11 施工总平面布置图
    4.12 重点难点分析
  五、合同条款偏离表
  六、技术标准偏离表
  七、廉洁投标承诺书
  八、资格审查资料
    8.1 营业执照
    8.2 资质证书
    8.3 安全生产许可证
    8.4 项目负责人资质证明
    8.5 企业业绩证明
    8.6 财务审计报告/财务报表
    8.7 信誉查询截图
    8.8 其他资格证明
  九、投标一览表/报价表
  十、招标代理服务费承诺书
  十一、投标保证金凭证

第二部分 经济标（如单独密封）
  工程量清单报价表

第三部分 电子版（单独密封）
```

## EPC/总承包项目投标文件目录

```
第一部分 商务文件
  投标函、授权书、资格证明等

第二部分 技术文件
  一、勘察设计说明和设计方案
  二、工程详细说明
  三、设备方案
  四、总体实施方案
  五、项目实施要点
  六、项目管理要点
  七、重点难点分析
  八、进度计划
  九、平面布置图及效果图

第三部分 经济文件
  投标报价
```

## 电子版要求参考

- 格式: 签字且加盖公章的PDF版本
- 文件命名: 第X包-项目名称-投标供应商名称
- 上传平台: 按招标文件指定的电子招投标平台
- 大小限制: 注意平台上传大小限制
