# 标书制作助手（Bid Creation）

## 产物呈现（强制）

本技能任何产出交付文件（docx/xlsx/pptx/pdf/png 等）的任务：

1. 文件落盘成功后立即登记：
   `python ~/.qidi/skills/office-artifact/scripts/card.py add <产物路径> --skill bid-creation --note <一句话说明>`
2. 任务最终回复前必须输出卡片总览：
   `python ~/.qidi/skills/office-artifact/scripts/card.py show`
3. 不许只回一行文件路径就结束；卡片失败则降级为 Markdown 表格列出全部产物。


把"招标文件 + 项目资料"高效转化为一份合规、结构完整、命中评分点的投标文件。

## 核心原则

1. **先读招标、再动笔** — 一切以招标文件（含澄清/补遗）为准，不得臆造资质、业绩、参数
2. **废标优先** — 每一步先识别废标/无效标条款，宁可暂停询问，也不产出会被否决的标书
3. **评分点驱动** — 商务标、技术标每一节对回评标办法中的评分项，标注"对应评分项 X.Y，可得分"
4. **证据链闭合** — 资质、业绩、人员、设备必须有对应证明材料索引
5. **格式即合规** — 份数、装订、密封、签字盖章、页码目录，任一项缺失都可能废标

## 流程总览

```
阶段0 角色确认 → 阶段1 招标文件解读 → 阶段2 目录框架 → 阶段3 资格审查册
→ 阶段4 商务标 → 阶段5 技术方案 → 阶段6 施工图表 → 阶段7 合规自检 → 阶段8 排版交付
```

---

## 阶段 0：角色与范围确认

- **采购类型**: 工程 / 货物 / 服务（决定章节模板）
- **角色视角**: 投标方编制 / 招标代理代写（决定措辞："我方" vs "投标人/供应商"）
- **覆盖范围**: 全套 / 仅商务 / 仅技术
- **招标文件来源**: 用户上传文件 (docx/pdf/txt) 或粘贴文本

---

## 阶段 1：招标文件解读

从招标文件提取并结构化，输出"投标要素表"给用户确认后再撰写：

| 要素 | 提取内容 | 去向 |
|------|---------|------|
| 项目概况 | 名称、编号、采购人、代理、预算/限价、工期 | 投标函、封面 |
| 资格审查条件 | 资质、财务、业绩、人员、社保、信誉 | 资格审查资料册 |
| 商务评分项 | 报价算法、业绩加分、认证加分 | 商务标 |
| 技术评分项 | 技术方案、实施、人员、设备分值分布 | 技术标 |
| 废标条款 | 串标、逾期、未盖章、未缴保证金等 | 阶段7自检 |
| 形式要求 | 份数、装订、密封、签章、封面格式 | 阶段8 |
| 时间节点 | 答疑截止、递交截止、开标时间 | 进度计划 |

**重点标注**: ★标记和黑体字条款通常为废标条件，必须逐条解读。区分"资格条件"（门槛）和"评分条件"（扣分）。业绩注意区分资格门槛业绩 vs 打分业绩。

> 若招标文件缺失关键项（如未给评分细则），**必须向用户指出并请求补充**，不要编造。

PDF 提取：`python pdfplumber` 逐页提取文本。大文件优先定位：招标公告、投标人须知前附表、评标办法、技术标准和要求、投标文件格式。

---

## 阶段 2：目录框架生成

按采购类型输出建议目录。以下为通用骨架，按评标办法增删。详见 [references/bid-structure.md](references/bid-structure.md)。

### 工程投标
```
第一册 资格审查资料 → 第二册 商务标 → 第三册 技术标
```
技术标含：施工组织设计、关键工艺、进度计划、质量保证、安全文明、劳动力/设备/材料计划、应急预案、项目管理机构

### 货物采购投标
```
第一册 资格审查资料 → 第二册 商务标 → 第三册 技术标
```
技术标含：技术规格响应、系统集成方案、供货物流、安装调试验收、培训、质保售后

### 服务采购投标
```
第一册 资格审查资料 → 第二册 商务标 → 第三册 技术标
```
技术标含：项目理解与思路、服务方案、组织架构与人员、进度计划、质量管控、保密应急沟通、增值服务

---

## 阶段 3：资格审查资料册

逐条对照资格条件，每项给出：
- **材料清单**（需用户提供的原件/扫描件）
- **自检结论**: 已具备 / 缺失（标红提示补齐）/ 需承诺替代

常用模板：法定代表人身份证明、授权委托书、各类承诺函（诚信/无串标/工期/质量/不转包/人员到位）、资格审查索引表

---

## 阶段 4：商务标

1. **投标函**: 按招标格式照填，金额大小写一致，币种准确
2. **报价策略提示**（仅内部不写入标书）: 合理低价优先时核算成本底线；含基准价公式时提示不同报价得分区间
3. **报价表**: 开标一览表、分项/工程量清单，合计与投标函一致
4. **商务偏离表**: 无偏离写"无偏离"并盖章；有偏离逐条说明且不触废标红线
5. **加分项证据**: 业绩、认证（ISO/高新等）、奖项附证明并注明对应评分项

---

## 阶段 5：技术方案撰写

每个项目的技术方案必须唯一，根据以下三维度动态适配：

### 5.1 评分标准驱动
- 评分维度、分值权重、档次要求决定章节结构和侧重点
- 每章节开头标注 `【对应评分项 X.Y，满分 N 分】`
- 评分细则中"包含但不限于"后面的内容必须全部覆盖

### 5.2 项目特征适配
- 提及具体的结构形式、材料规格、施工工艺
- 针对工程类型（钢结构/市政/EPC/房建）写针对性方案
- 采用行业先进工艺，具体化工艺参数，引用规范标准编号
- 措施具体到可执行层面：明确责任人、时间节点、检查标准

### 5.3 地域特征适配
| 地区 | 自动加入的内容 |
|------|--------------|
| 东北/西北 | 冬季施工专项措施、防冻保温、混凝土冬施、低温焊接 |
| 南方 | 雨季施工、防暑降温、台风应急、排水防涝 |
| 高原 | 高原施工注意事项、人员健康保障 |
| 城区 | 扬尘治理、噪声控制、交通疏导、夜间施工限制 |
| 沿海 | 防腐蚀、防台风、地下水位处理 |

### 5.4 评分档次对标
对标最高档次要求。如"完善"需"内容全面、针对性强、关键节点论述清晰、可提出相关案例"，则必须做到。每章节末尾可加"本项目特色做法"突出针对性。

## 阶段 6：施工图表生成

所有图表针对具体项目生成，不使用通用示意图。

| 图表类型 | 生成方式 | 输入要求 |
|----------|---------|---------|
| 施工总平面布置图 | matplotlib/PIL/SVG | 场地尺寸、建筑位置、临设需求 |
| 现场布置图 | matplotlib/SVG | 施工区域、机械布置、材料堆场 |
| 各阶段施工效果图 | 图像生成 | 建筑类型、施工阶段、环境特征 |
| 最终效果图 | 图像生成 | 建筑外观、周边环境 |
| 网络图（双代号/单代号） | matplotlib | 工序列表、工期、逻辑关系 |
| 横道图（甘特图） | matplotlib | 总工期、分项工程、持续时间 |

**输出规范**: PNG/SVG，适合A4插入（宽约17cm，2000px@300dpi）；中文用黑体/宋体；专业工程图风格（**配色以本项目招标文件要求为准**：要求黑白的按黑白绘制、关键路径红色标注；无黑白要求的用彩色专业工程配色——深蓝主线/橙警示/青平行工序/暖灰道路，参考南谯区项目 gen_* 彩色图实践）；带标题栏。

---

## 阶段 7：合规自检（废标风险）

生成前必须输出"废标风险核对清单"，逐条打勾：

- [ ] 投标截止时间前可完成签署封装
- [ ] 投标保证金已缴、凭证有效
- [ ] 法定代表人或授权人签字、单位公章齐全，无漏页漏章
- [ ] 资质/业绩/人员未弄虚作假，与证明材料一致
- [ ] 报价未超最高限价，大小写一致
- [ ] 商务/技术偏离未超出允许范围
- [ ] 未出现串标/围标情形
- [ ] 份数、装订、密封、封面格式符合要求
- [ ] 资格审查硬性条件 100% 满足

**任一未满足 → 暂停并明确告知用户，不得带病交付。**

---

## 阶段 8：排版与交付

### 投标文件结构编排
1. 确定目录结构（以招标文件"投标文件格式"章节为准）
2. 编制评分索引表（评分项 → 对应内容 → 页码）
3. 整合各章节，插入图表，编排连续页码
4. 编制目录，检查交叉引用

### 排版规范
| 项目 | 规范 |
|------|------|
| 纸张 | A4 |
| 页边距 | 上下2.54cm，左右3.17cm（或按招标要求） |
| 正文 | 宋体小四号(12pt)，1.5倍行距 |
| 标题 | 黑体（章三号/节四号） |
| 页码 | 底部居中，连续编排 |
| 表格 | 五号宋体，表头加粗，边框完整 |
| 图片 | 居中，图号+图名在下方 |
| 装订 | 胶装成册，不得活页 |

### 输出
- 生成 Word 文档（.docx），可用 office-tools skill 的 Markdown 管道或 docx-js 生成
- 如需 PDF 版本，用 LibreOffice 转换（注意签章需纸质版）
- 文件命名按招标要求
- 所有需盖章位置用【此处加盖公章】标注提醒

### 常用模板

商务偏离表、技术偏离表、资格审查索引表、投标函骨架详见 [references/bid-templates.md](references/bid-templates.md)。

## 注意事项

- 本 skill 负责"组织与撰写"，**不替代法律顾问与造价/技术负责人的最终审核**
- 所有金额、资质、业绩、参数均须用户提供真实材料
- 招标文件更新（澄清/补遗）后，须重新跑阶段 1 与阶段 7
- 招标代理场景下，把"我方"统一替换为"投标人/供应商"
- 可参考历史方案结构和写法，但内容必须针对当前项目重新撰写

## 配合 office-tools skill 使用

- Word 文档生成: `python scripts/md_to_docx.py` 或 `python scripts/word_ops.py`
- PDF 提取: `python scripts/pdf_ops.py extract-text`
- Excel 报价表: `python scripts/excel_ops.py`
- 图表生成后插入 Word
- 格式转换: LibreOffice (`soffice --headless --convert-to pdf`)
