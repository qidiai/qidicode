# Phase C 前置实验：reasoning 块清理对续写质量的影响（双臂盲测）

> 2026-10-12。Phase C 设计决策 #1（reasoning 是否纳入低水位批量清）的前置实验。用户裁决链：先实验再拍板 → 本实验完成后定夺。

## 实验设计

- **变量唯一**：assistant 历史消息中的【思考】推理文本块——A 臂保留 vs B 臂剥离（strip 形态），其余消息逐字节一致（脚本内置断言自检）
- **任务集**：6 任务（诊断排除/方案取舍/数据推演/设计约束/排除法记忆/跨轮引用），续写提问设计为**只有读到早期思考过程才答得准**；t3（数据推演）为对照组——答案可从提问内参数重算，预期 A/B 无差异，构成**实验内部有效性校验**
- **模型**：GLM-5.3（max_tokens 16384，思考模型预算实测修正）+ kimi-k2.7-code（1500），luyou 端点，temperature=0
- **执行**：24/24 调用成功（零 429），零编译
- **裁判**：K3 独立盲评（X/Y 匿名随机映射，禁读 map），指挥官揭盲

## 结果（揭盲后）

### 臂别对照总账

| 臂 | 胜 | 负 | 平 |
|---|---|---|---|
| **A（保留思考）** | **10** | **0** | 2 |
| **B（剥离思考）** | 0 | 10 | 2 |

2 平均为 t3 对照组（设计内预期收敛，校验通过）。

### 质量缺陷分布（全部在 B 臂）

| 类型 | 实例 |
|---|---|
| 编造 ×5 | GLM-B t1 虚构"30s 采样粒度"；GLM-B t2 虚构"强一致只有三条实现路径"；GLM-B t4 虚构"MISRA/IEC 61508"且与材料约束②直接矛盾；kimi-B t2 虚构"热 key 串行化"；kimi-B t5 把 GPL 错配到 3/4 号候选 |
| 因果错置 ×1 | kimi-B t1 把"排除依据"错述为"回滚后恢复"（时间线矛盾） |
| 输出崩坏 ×1 | kimi-B t4 中段重复循环截断 |

### 关键模式

1. **B 臂退化模式不是"含糊"而是"编造"**：用通用领域知识重写答案，看似专业实则架空材料（逐字数字、排除依据、隐藏约束全部丢失后以貌似合理的虚构填补）。
2. **部分清理比全量 compact 更危险**：compact 是全量重建（模型从摘要重启，无"看到正文却看不到推导"的落差）；低水位清 reasoning 保留正文结论——模型假设推导与正文一致并用通用知识补齐——编造的直接来源。
3. **考古证据（4 生产路径无故障）与实验证据的调和**：无故障记录 ≠ 无质量损失——损失存在但从未被测量/归因。本实验就是那次测量。
4. GLM-5.3 副发现：历史含【思考】块时模型会模仿该格式输出；思考模型 reasoning_content 计入 max_tokens（预算实测：16384 方完整）。

## 对 Phase C 的含义

- 维持 C-1（不清 reasoning）→ 低水位 batched 只清 ToolResult，O-4 实测收益中位 **0.6%**——机制形同虚设
- 纳入 reasoning 裸清 → 本实验证伪（质量代价压倒性）
- **可行方向**：清 reasoning 原文时**摘要化保留关键事实**（数字、排除依据、隐藏约束压缩为 1-3 行留存）——K3 裁判独立建议同向（"至少以摘要形式保留关键数字与排除依据"）；或高龄阈值+档案回捞指引折中（O-14 已证档案层全量保留）
