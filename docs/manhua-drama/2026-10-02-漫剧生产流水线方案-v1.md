## 0. 目标

| 项 | 值 |
|---|---|
| 首部样片 | 30-60 秒竖屏漫剧（9:16, 720x1280, H.264 mp4） |
| 形态 | 静帧分镜图 + Ken Burns 运镜 + 多角色配音 + 字幕 |
| 成本 | 样片 **¥0**（全本地出图 + edge-tts 免费 + ffmpeg 合成；vision 扫图仅抽检） |
| 里程碑 | 本周内出片（M1→M5，见 §7） |
| 升级路径 | 关键镜头换 agnes-video-2.5 I2V（¥0.15/秒） |

## 1. 流水线总览（六环节）

```
S1 剧本/分镜 → S2 角色卡+设定图 → S3 分镜图(参考图工作流) → S4 配音 → S5 合成 → S6 交付
```

| 环节 | 工具 | 输入 | 输出 | 耗时 |
|---|---|---|---|---|
| S1 剧本分镜 | 中转免费池 + novel-craft 资料；**YAML 人工覆盖可绕过** | 章节文本/创意 | `storyboard.json` | ~10 min |
| S2 角色卡 | drama-character-card | 原著/设定 | 角色卡 + **角色设定图 sheet（参考图）** | ~30 min |
| S3 分镜图 | 本地 ComfyUI Qwen-Image-2.1 int8 + **QwenImage21Cache 参考图工作流** | storyboard + 设定图 | `shots/shot-XX.png` | 瓶颈：int8 ~10min/图（turbo 草稿 ~2min/图） |
| S4 配音 | edge-tts | 台词表 + 音色映射 | `audio/shot-XX.mp3` + ffprobe 实测时长 | 分钟级 |
| S5 合成 | ffmpeg（scale+crop 运镜 + concat + 字幕） | 图 + 音 + 字幕 | `output/成片.mp4` | 分钟级 |
| S6 交付 | office-artifact 登记 + license_check.md | 成片 | 产物卡片 + 归档 | - |

## 2. 关键设计决策

### 2.1 画幅与构图（P1-1 修订）
- 出图用 **1024² 方图**（唯一实测稳定档），但分镜阶段即按**竖屏安全区模板**约束构图：主体集中在中央 576×1024 区域（9:16 等比），提示词末尾追加构图约束
- `storyboard.json` 每镜头增加 `framing: "center|left|right|top|bottom"` 字段，`compose.py` 按 framing 做非对称裁切（前景 crop 到 576 宽等比 → 放大至 720×1280），不再固定居中
- M2 可选实测：竖屏原生出图 720×1280（16 倍数），通过则样片直接采用

### 2.2 分镜 JSON Schema v2（下游唯一契约）

```json
{
  "project": "proj1",
  "aspect": "9:16",
  "fps": 30,
  "characters": [
    {"id": "CH-01", "name": "主角", "card": "character-cards/cards/ch-01.json",
     "ref_sheet": "character-cards/images/ch01-sheet.png",
     "tts_voice": "zh-CN-YunxiNeural", "tts_fallback": "zh-CN-YunyangNeural",
     "tts_rate": "+0%", "tts_pitch": "+0Hz"}
  ],
  "shots": [
    {
      "shot_id": "S01",
      "image_prompt": "英文提示词（角色锁定短语由脚本从角色卡自动拼接）",
      "use_ref": ["CH-01"],
      "framing": "center",
      "camera": "zoom-in | zoom-out | pan-left | pan-right | static",
      "camera_easing": "linear | ease-in-out",
      "dialogue": [{"character": "CH-01", "line": "台词"}],
      "narration": "旁白（可空）",
      "sfx": "whoosh（可空，样片期仅转场音效）",
      "min_duration_sec": 3.0,
      "subtitle": "画面字幕（可空）"
    }
  ],
  "transitions": [{"after_shot": "S01", "type": "fade", "duration": 0.3}]
}
```

- 镜头时长 = `max(配音时长 + 0.5s, min_duration_sec)`，配音先行定时长
- `use_ref` 指定该镜头参考哪些角色的设定图（见 §2.4）
- 全局时间轴由 `compose.py` 计算并于合成前输出校验表（每镜头起止 + 总时长）

### 2.3 音色分配（P2-1 修订）
- 音色注册表落在 `characters[]`；**主要角色 ≤5**，超出用 fallback 音色 + rate/pitch 参数区分
- edge-tts 参数显式化：`rate`/`pitch`/`volume` 入角色卡

### 2.4 角色一致性技术栈（P0-1 修订，本版核心增量）

**主路线：Qwen-Image-2.1 原生参考图工作流**
- S2 产出的**角色设定图 sheet（三视图）作为参考图**，经 ComfyUI `QwenImage21Cache`（device=auto/cpu）注入参考图前缀 KV 缓存 → 分镜图生成以设定图为视觉锚（qwen-image-lowvram 已验证该节点可用，官方同推图生图/场景效果）
- 工作流 API JSON 固化进 `tools/manhua/workflows/`（见 §3.1 manifest），禁止运行时手拼
- `use_ref` 为空的空镜/物件镜头走纯文生图，不挂参考缓存

**验收（P2-6 修订）**：角色相似度目测 ≥80%、无乱码文字、无畸形手指、线条闭合、服化道与角色卡一致；制作人对每镜头按此清单打分，不合格进重生成队列

**Fallback 链**：参考图工作流出片不合格 → 调整参考图权重/prompt 强化重试 2 次 → 仍不合格改分镜（换景别规避正脸）→ 记录进 `issues.md`

**明确不做（样片期）**：LoRA 训练（数据/时间不划算）、InstantID/IP-Adapter（SDXL 生态，不适配 Qwen-Image 架构）

### 2.5 S1 降级策略（P1-3 修订）
- `gen_storyboard.py`：免费池调用带指数退避，**连续 3 次失败 → 熔断**并提示人工
- storyboard 允许**人工 YAML 覆盖**：`storyboard.override.yaml` 与 JSON 同 schema，人工优先——LLM 只产草稿，分镜最终拍板在人
- 不引入本地 Ollama 依赖（本机 16GB 内存与 ComfyUI 冲突，不值得）

### 2.6 中间文件全 ASCII 路径（P1-4 修订）
- **工作区**：`qidiwork-docs/manhua/proj1/`（ASCII），全部中间产物（storyboard/图/音/片段/字幕/成片）都在这里
- **最终交付**才复制到中文展示目录 `qidiwork-docs/漫剧/<项目名>/`
- `compose.py` 所有 ffmpeg 调用用 `subprocess.run(list)` 显式参数（禁 shell 字符串），`encoding="utf-8"`；字幕用 ASS（UTF-8），ffmpeg 读取路径全 ASCII

## 3. 脚本清单（`tools/manhua/`，进 git）

| 脚本 | 职责 | 关键工程要求 |
|---|---|---|
| `gen_storyboard.py` | 免费池生成分镜草稿 | 指数退避 + 3 次熔断；YAML 覆盖优先 |
| `gen_shots.py` | 批量出图（参考图工作流） | **断点续传**（P1-5）：`state.json` 记录每镜头状态，已落盘自动跳过；单图 3 次重试；**ComfyUI 心跳**（/health 5 分钟无响应→告警并终止队列，人工介入）；落盘前查磁盘剩余 >10GB（P2-9） |
| `gen_tts.py` | edge-tts 逐镜头合成 | 退避重试（429）；ffprobe 实测时长回填 storyboard；输出统一重采样 48kHz |
| `compose.py` | 合成成片 | 见 §3.2 |
| `check_shots.py` | **辅助标记**（P1-2 降级） | 免费池 vision 抽检 10% + 人工标记可疑项；输出建议分，**不做硬门槛**；人工终审清单为准 |

### 3.1 环境可复现 manifest（P2-8 修订）
`tools/manhua/manifest.json`：ComfyUI workflow API JSON（入 git）+ 自定义节点 commit hash + 模型文件 checksum + ComfyUI 版本。`gen_shots.py` 启动时校验 manifest 与本机环境一致性，不一致则拒绝运行并提示差异。

### 3.2 合成工程规范（P1-6/P1-7/P2-4 修订）
- **运镜**：放弃单层 zoompan（亚像素抖动），采用 **scale 放大（1.25×）→ crop 逐帧 offset** 方案，运镜曲线按 `camera_easing` 生成；M2 先产出 5 秒测试片段验证平滑度，通过后才批量
- **对轴**：每镜头视频帧数 = `ceil(audio_sec × fps)`，`-t 帧边界`精确截断；concat 用 demuxer + 统一重编码（同 fps/时间基/像素格式）；音频全链 `aresample=48000`，aac 192k
- **编码模板常量**：`libx264 / crf 23 / preset medium / profile high / level 4.0 / yuv420p / r 30`
- **后置校验**：成片 ffprobe 实测时长 vs storyboard 累计时长误差 **<100ms**，超差报警
- **字幕规范**（P2-3）：距底 ≥200px，思源黑体/阿里巴巴普惠体，白字黑描边，单行 ≤15 字；`framing=bottom` 镜头字幕自动上移
- **混音**（P2-2）：BGM 音量 -18dB 起，人声段 sidechaincompress ducking；样片期 SFX 仅转场 whoosh

## 5. 成本与产能核算

> **M2 实测校准（2026-10-02，编码手实测 + 指挥官复核）**：参考图工作流稳态 **~24.9 s/it ≈ 纯 T2I（11.43 s/it）的 2.2×**，单张热跑 **~11 min**（首步还有 112-204s 模型初始化/冷启）。QwenImage21Cache **默认 device=cpu**（与 auto 稳态同速但可预测、不吃显存余量；实测差异主要来自冷/热启顺序非 device 本身）。

| 档位 | 配方 | 2 分钟片成本 | 产能（M2 校准后） |
|---|---|---|---|
| 第一档（本方案） | 全静帧+运镜 | **¥0** | **瓶颈更新：40 镜头全走参考图 ≈ 7.5h（同会话连续跑复用已载模型）**；turbo 草稿轮仍 ~1.5h；无角色出场的纯空镜镜头走纯 T2I（11.43 s/it，~6.5min/图）可摊薄 |
| 第二档（预留） | 1/3 镜头 I2V（agnes @720P） | ≈ **¥4-6** | +1h 无人值守 |
| 第二档全量 | 全镜头 I2V | ≈ ¥18 | 同上 |

## 6. 风险与已知坑（v1.1 增补）

| # | 风险 | 对策 |
|---|---|---|
| R1 | ffmpeg 未装（实测缺失） | M2 首项：static build → `F:\AI\tools\ffmpeg\`，PATH 注入 |
| R2 | 显存互斥：ComfyUI(4.7GB) ↔ HunyuanOCR(3.3GB) ↔ 6GB | 流水线分时；TTS 走 edge-tts 云端不占本地 GPU |

| R5b | **ComfyUI Autogrow 输入嵌套 dict 静默失效**（M2 实测 P0） | workflow 必须用扁平点号键 `images.image_1`；manifest sha256 校验防回归；resolution=0 探针可复验 |

| R8 | **角色一致性漂移**（P0） | §2.4 参考图工作流 + fallback 链 + 验收清单 |
| R9 | 过夜批量中断（P1-5） | state.json 断点续传 + 3 次重试 + 心跳告警 + 磁盘预检 |
| R10 | 中文路径编码（P1-4） | 全 ASCII 工作区 + subprocess list + ASS 字幕 |
| R11 | 许可证边界（P2-7） | S6 前 `license_check.md`：Qwen-Image-2.1（RESEARCH LICENSE，**商用需授权**，样片仅内部验证）、edge-tts（禁商用）、BGM/字体许可证记录；样片标记"仅内部验证"不对外发布 |
